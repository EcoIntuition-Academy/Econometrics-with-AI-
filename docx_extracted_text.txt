Econometrics is the craft of using data to answer “what if” questions about the world in a disciplined way. The central object is usually a regression model, which tries to separate the systematic part of an outcome from the noisy part.​
Two main goals motivate almost everything:
{Causal questions.} Does changing variable actively change variable ? Does education cause higher wages? Do smaller classes cause higher test scores?.​
{Prediction.} Even if the mechanism is unclear, can past data be used to predict future inflation, demand, or sales? .​
A helpful mental picture is that causality asks about \emph{parallel universes}: what would happen to the same unit if a treatment were different but everything else stayed fixed. Prediction, in contrast, is more modest: it merely asks whether a pattern in past data is reliably repeated in the future.​
2. Correlation vs causation: the class-size story
Consider the example: smaller classes are observed to have higher test scores. At first glance, a scatter plot of class size on the horizontal axis and test scores on the vertical axis might show a clear downward trend.​
However, this correlation is not yet a causal claim. Hidden variables may be bending the picture:
{Teacher quality.} Perhaps better teachers tend to be assigned to smaller classes, and those teachers raise test scores.​
{Parental involvement.} More involved parents may succeed in moving their children into smaller classes, and these parents also support higher test scores through home environment.​
So the world might be:
Class size is small because of better teachers and more involved parents.
Test scores are high because of those same teachers and parents.
The result: smaller classes and higher scores move together, but class size is not the fundamental lever.​
This matters because the policy question is: should public money be spent on reducing class sizes, or on improving teacher quality, or on something else? Only if the effect of class size on test scores is genuinely causal does the policy of reducing class size become justified.​

5. The CLRM assumptions: why they exist
OLS is just a computational recipe unless backed by assumptions that connect data to the underlying population model. The “Classical Linear Regression Model” (CLRM) is defined by a set of assumptions under which OLS estimators have attractive properties like unbiasedness, consistency, and efficiency.​
Each assumption has its own intuitive role:
Linearity in parameters: keeps the model in a linear space where projections make sense.​
Full rank: ensures the regressor space is well-defined and not degenerate.​
Exogeneity: decouples regressors from the noise so that the projection direction reflects the true relationship.​
Homoskedasticity and no autocorrelation: keep the noise “equally spread” and uncorrelated across observations, enabling standard error formulas and efficiency.​
Fixed/random regressors: clarify what is treated as given in probability statements.​
Normality: provides exact finite-sample distributions for test statistics.​

The variance–covariance matrix is just a constant time the identity: equal variance, zero covariance.​
Violations:
If diagonal elements differ, some observations have larger error variance: heteroskedasticity.​
If off-diagonal elements are nonzero, errors move together across observations: autocorrelation.​
Concrete heteroskedasticity example: traffic fatalities across states.​
Large states (like Pennsylvania) have more drivers and thus potentially larger variance in fatalities.
Small states (like Delaware) have fewer drivers and smaller variance.​
Even after controlling for population, the spread of residuals may still grow with state size.​
Concrete autocorrelation example: time series of quarterly GDP.​
A negative shock this quarter is often followed by another negative shock next quarter.
Residuals exhibit runs of positive or negative values rather than flipping randomly.​

Invalidate the usual standard error formulas and thus and tests unless corrections are used.​
