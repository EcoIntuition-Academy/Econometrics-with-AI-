LESSON 2.2 Matrix Calculus

Deriving the Normal Equations

Follow the matrix calculus derivation in slow motion: expanding the sum of squared residuals \(S(b)\), computing the gradient vector, establishing the normal equations \(X'X\hat{\beta} = X'y\), and verifying the positive definite Hessian.

🎯 Learning Objectives

  • Maintain strict notation discipline: true population \(\beta\), candidate vector \(b\), and OLS estimate \(\hat{\beta}\).
  • Expand the quadratic objective function \(S(b) = (y - Xb)'(y - Xb)\) using matrix transpose laws.
  • Differentiate \(S(b)\) with respect to \(b\) to obtain the gradient \(\nabla S(b) = -2X'y + 2X'Xb\).
  • Solve the first-order condition to derive the Normal Equations \(X'X\hat{\beta} = X'y\) and closed-form estimator \(\hat{\beta} = (X'X)^{-1}X'y\).
  • Check the Hessian matrix \(2X'X\) and confirm the second-order condition for a unique global minimum.

1. The Linear Regression Model & Objective Function

Start from the classical linear regression model in matrix form:

POPULATION MODEL Matrix Representation of the Model
$$y = X\beta + \varepsilon$$
WHERE
\(y\) \(n \times 1\) observed outcome vector
\(X\) \(n \times k\) design matrix of regressors
\(\beta\) \(k \times 1\) population coefficient vector
\(\varepsilon\) \(n \times 1\) population disturbance vector
NOTATION DISCIPLINE
\(\beta\) Unknown population coefficient vector fixed by nature.
\(b\) Candidate coefficient vector used when evaluating the loss function.
\(\hat{\beta}\) The specific value of candidate vector \(b\) that minimizes the OLS objective.

The OLS idea is simple in words: choose \(\hat{\beta}\) so that the sum of squared residuals—the squared Euclidean distance between what is observed and what is predicted—is as small as possible.

For any candidate coefficient vector \(b\), the candidate residual vector is:

$$e(b) = y - Xb$$

Here, \(e(b)\) is the residual vector in \(n\)-dimensional observation space associated with trial vector \(b\). It is not the unobservable population disturbance \(\varepsilon\).

The objective function to be minimized is the sum of squared residuals:

OBJECTIVE FUNCTION Sum of Squared Residuals \(S(b)\)
$$S(b) = e(b)'e(b) = (y - Xb)'(y - Xb)$$
WHERE
\(S(b)\) Sum of squared residuals evaluated at candidate vector \(b\)
\(b\) Candidate \(k \times 1\) coefficient vector
\(Xb\) Candidate fitted vector in \(\operatorname{Col}(X)\)
\(y - Xb\) Candidate residual vector in observation space \(\mathbb{R}^n\)

2. Deriving the Normal Equations in Slow Motion

To see how the minimization operates algebraically, we expand and differentiate the objective function step by step:

STEP 1 State the Objective Function
$$S(b) = (y - Xb)'(y - Xb)$$

The inner product of the residual vector with itself gives the sum of squared residuals \(\sum_{i=1}^n e_i(b)^2\).

STEP 2 Expand Using the Transpose Law \((A - B)' = A' - B'\)
$$S(b) = y'y - b'X'y - y'Xb + b'X'Xb$$

Applying the distributive property of matrix multiplication produces four distinct matrix terms.

STEP 3 Combine Middle Terms via Scalar Symmetry
$$b'X'y = (Xb)'y = y'Xb \implies S(b) = y'y - 2b'X'y + b'X'Xb$$

Because \(b'X'y\) is a \(1 \times 1\) scalar, it equals its own transpose: \((b'X'y)' = y'(X')' (b')' = y'Xb\). Thus, the two middle terms combine into \(-2b'X'y\).

STEP 4 Differentiate with Respect to Candidate Vector \(b\)
$$\frac{\partial S(b)}{\partial b} = -2X'y + 2X'Xb$$

Using standard matrix calculus identities: \(\frac{\partial (a'b)}{\partial b} = a\) and \(\frac{\partial (b'Ab)}{\partial b} = 2Ab\) for symmetric matrix \(A = X'X\).

STEP 5 First-Order Condition (Set Gradient to Zero)
$$-2X'y + 2X'X\hat{\beta} = 0 \implies X'X\hat{\beta} = X'y$$

Setting the derivative equal to zero identifies the stationary point \(\hat{\beta}\). These are the celebrated Normal Equations.

STEP 6 Solve for the Unique Closed-Form Estimator
$$\hat{\beta} = (X'X)^{-1}X'y$$

Under Assumption A2 (Full Column Rank \(\text{rank}(X) = k\)), the \(k \times k\) matrix \(X'X\) is strictly non-singular and invertible, guaranteeing a unique solution!

FIRST-ORDER CONDITION The Normal Equations
$$X'X\hat{\beta} = X'y$$
WHERE
\(X'X\) \(k \times k\) cross-product matrix of regressors
\(X'y\) \(k \times 1\) cross-product vector between regressors and outcome
\(\hat{\beta}\) At the OLS solution, no infinitesimal movement in coefficient space can reduce the sum of squared residuals.

When \(X\) has full column rank, \(X'X\) is non-singular and invertible, yielding the closed-form estimator:

$$\hat{\beta} = (X'X)^{-1}X'y$$

3. Second-Order Condition: Confirming a Global Minimum

The first-order condition locates a stationary point where the gradient vanishes. To verify whether \(\hat{\beta}\) is a minimum, maximum, or saddle point, we evaluate the second-derivative Hessian matrix:

$$\frac{\partial^2 S(b)}{\partial b \partial b'} = 2X'X$$

WHY THIS MATTERS

The first-order condition finds a stationary point. Positive definiteness of the Hessian confirms that the stationary point is a unique global minimum. When \(X\) has full column rank (\(\text{rank}(X) = k\)), for every non-zero vector \(v \in \mathbb{R}^k\), \(v'(2X'X)v = 2\|Xv\|^2 > 0\). Hence, \(X'X\) is strictly positive definite, the loss surface \(S(b)\) is strictly convex (a multidimensional bowl), and \(\hat{\beta}\) is guaranteed to be the unique minimizer.
