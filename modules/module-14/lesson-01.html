LESSON 14.1 Experimental Design

Minimum Detectable Effects & Experimental Feasibility

Calculating sample size is not merely an abstract statistical exercise. Learn how to target minimum detectable effects that reflect actionable policy thresholds, navigate research budget trade-offs, and establish safe control variable guidelines.

LEARNING OBJECTIVES
  • Define the Minimum Detectable Effect (MDE) in experimental planning.
  • Connect statistical detectability to practical, actionable policy relevance.
  • Analyze the cost-precision trade-off linking sample size, budget constraints, and MDE.
  • Interpret the animal-search intuition connecting detectable magnitude to research value.
  • Distinguish valid pre-treatment covariates from dangerous post-treatment variables.

1. The Minimum Detectable Effect (MDE)

CORE DEFINITION

Minimum Detectable Effect (MDE)

The Minimum Detectable Effect (MDE) is the smallest true treatment effect size that a given experimental design is capable of detecting with the intended statistical significance and power.

PLANNING QUESTION

What MDE Should We Aim For?

The MDE informs the researcher about what effect size could be detected with a given sample size and design. But the central economic question is: Is that MDE large enough to justify undertaking the study? Ideally, researchers design studies around the smallest effect that policymakers or decision-makers would still find actionable.

STATISTICALLY DETECTABLE

An effect magnitude that the experimental sample size and variance can distinguish from zero with acceptable type I and type II error rates.

POLICY RELEVANT & ACTIONABLE

An effect large enough to alter institutional decisions, justify program implementation costs, or scale up a social intervention.

INTUITIVE ANALOGY · DETECTING AN EFFECT

Searching for Wildlife: Lion, Leopard, or Serval?

Suppose villages report that a wild cat is threatening livestock. A quick, inexpensive search can readily find a lion (a massive, unmistakable effect). Finding a secretive leopard requires more tracking effort and resources, but may still be actionable.

However, spending immense resources on an exhaustive expedition just to spot a serval—a cat so small and inconsequential that no public policy would change—is economically wasteful. Do not design an expensive trial to detect an effect too small to matter.

3. Implementation Considerations & Control Variables

IMPLEMENTATION CAUTION

The Imperfect Compliance Risk

Even a perfectly powered study can run into severe difficulties if assigned individuals do not actually take up the treatment (e.g., selling subsidized medicine rather than consuming it). When assignment diverges from receipt, experimental evaluation requires specialized instrumental-variables tools (developed in Lessons 14.4–14.6).

Rules for Baseline Control Variables

PREFERRED · PRE-TREATMENT

Use covariates measured strictly before the experiment begins. Because they predate treatment, they cannot be influenced by it.

PERMISSIBLE · UNAFFECTED IN-TREATMENT

In-treatment variables are safe only if external forces ensure they cannot be influenced by assignment (e.g., state cigarette tax in a smoking trial).

DANGEROUS · TREATMENT-AFFECTED

Never control for variables altered by the intervention. Doing so creates bad controls, inducing bias in the treatment effect estimate.

5. Quick Check

QUICK CHECK

Why is the smallest statistically detectable effect not automatically the correct target for an experimental study?

HINT: Consider whether an effect too tiny to trigger policy action justifies an expensive, large-scale search.

ANSWER: Because the target effect size must also be large enough to matter for the policy, decision, or investment the study is meant to inform.

WHY? Detecting an extraordinarily tiny effect requires massive sample sizes and research budgets. If decision-makers would not take action on an effect of that small magnitude, the additional expenditure to detect it produces no social or policy value. Studies should be powered for actionable effects.

TAKEAWAYS

What You Should Now Understand

  • The Minimum Detectable Effect (MDE) defines the precision threshold of an experimental design.
  • Researchers should align MDE targets with the smallest effect size that would remain policy-actionable.
  • Increasing sample size reduces MDE but increases study implementation costs.
  • Like searching for lions vs. servals, chasing inconsequential effects wastes research capital.
  • Use pre-treatment covariates for precision; never control for variables affected by treatment.
