LESSON 15.4 LOCAL ESTIMATION & BANDWIDTH

Bandwidth Choice, Local Estimation & Kernel Weighting

Navigate the fundamental bias-variance trade-off in bandwidth selection, evaluate bandwidth sensitivity, and apply kernel weighting schemes for local polynomial estimation.

LEARNING OBJECTIVES
  • Define the estimation bandwidth h and the local sample window [a₀ - h, a₀ + h].
  • Explain the core bias-variance trade-off governing bandwidth width.
  • Interpret bandwidth sensitivity graphs displaying point estimates across varying window sizes.
  • Apply the triangular kernel weighting function to prioritize observations closest to the threshold.

1. What is a Bandwidth in Regression Discontinuity?

BANDWIDTH DEFINITION · LOCAL ESTIMATION WINDOW

The bandwidth (\(b\)) defines how close to the cutoff an observation must be in order to enter the local RD comparison.

\[ a_0 - b < a_i < a_0 + b \]

Observations with running variable values outside this symmetric window are excluded from the estimation sample.

CANONICAL APPLICATION · ACADEMY SCORE THRESHOLD

Cutoff \(a_0 = 500\) with Bandwidth \(b = 25\)

If the academy admission cutoff is \(a_0 = 500\) and the researcher selects a bandwidth of \(b = 25\), the regression sample is restricted strictly to students scoring between 475 and 525: \[ 500 - 25 < a_i < 500 + 25 \iff 475 < a_i < 525 \] Students scoring 420 or 650 are discarded from local regression fitting.

2. The Core Bias?"Variance / Comparability Trade-off

Choosing the bandwidth \(b\) is the defining practical decision in local RD estimation. It represents a direct tension between statistical precision and causal comparability:

BANDWIDTH TOO NARROW

High Variance & Low Precision

• Few Observations: Sample size \(N_{\text{local}}\) collapses.
• Large Standard Errors: Inflated sampling uncertainty.
• Wide CIs: Low statistical power to detect meaningful impacts.
BANDWIDTH TOO WIDE

Comparability Threat & Potential Bias

• More Observations: Standard errors shrink substantially.
• Distant Units Differ: Units far from \(a_0\) diverge in unobservables.
• Specification Error: Mis-specifying curvature introduces bias into \(\hat{\beta}\).
PRACTICE STANDARD

There is No Single "Universal" Bandwidth

Econometric theory and applied consensus emphasize that no single bandwidth is universally correct. Best practice relies on a combination of:

  1. Substantive Theory: Domain knowledge regarding the range over which units remain plausible counterfactuals.
  2. Bandwidth Sensitivity Diagnostics: Estimating \(\hat{\beta}\) across multiple bandwidths (e.g., \(0.5\hat{b}\), \(\hat{b}\), \(1.5\hat{b}\), \(2\hat{b}\)) to verify qualitative stability.
  3. Data-Driven Optimal Procedures: Algorithmic mean-squared-error (MSE) or coverage-error-rate optimal selectors (e.g., Imbens & Kalyanaraman, 2012; Cattaneo & Vázquez-Bare, 2016).

4. Kernel Weighting & The Triangular Kernel

Within a selected bandwidth window \(a_0 \pm b\), should every observation be treated equally? Standard local linear regression applies kernel weighting:

KERNEL WEIGHTING DEFINITION

In kernel weighting, observations closer to the cutoff \(a_0\) receive the highest weight in estimation, while weights decline for observations situated near the outer boundaries of the bandwidth.

\[ K(u) = (1 - |u|) \cdot \mathbf{1}(|u| \le 1), \quad \text{where } u = \frac{a_i - a_0}{b} \]

The Triangular Kernel: The triangular kernel assigns maximum weight \(K(0) = 1\) directly at the threshold \(a_0\), tapering down linearly to \(0\) at the bandwidth edges \(a_0 - b\) and \(a_0 + b\). It emphasizes units with the strongest local comparability without relying on distant units.

TRIANGULAR KERNEL WEIGHT FUNCTION Optimal Boundary Properties
Academic Precision Note: A triangular kernel does not magically "eliminate bias." Rather, it has mathematically optimal properties for boundary estimation in local linear regression (minimizing asymptotic mean-squared error at boundary points).

Quick Knowledge Check

Question: What is the main statistical trade-off when an empirical researcher chooses a very narrow bandwidth?

Consider how sample size and comparability change as you look closer and closer to the threshold.

Solution:
The observations are more local to the cutoff, but fewer observations remain, increasing sampling uncertainty.

A narrower bandwidth ensures that the units being compared are as close as possible to the cutoff, minimizing potential bias from curvature or unobserved confounders. However, it severely reduces the effective sample size \(N_{\text{local}}\), inflating the variance of \(\hat{\beta}\) and producing wider confidence intervals.

Lesson 15.4 Summary

Bandwidth selection governs the fundamental bias-variance trade-off in nonparametric and local linear RD estimation. Narrow windows minimize specification bias by comparing units closest to the threshold, but inflate sampling variance due to reduced sample sizes. Data-driven algorithms optimize this trade-off, while triangular kernels assign maximum weight to observations at the cutoff. Robust empirical practice requires presenting bandwidth sensitivity curves to prove findings are stable across windows.
