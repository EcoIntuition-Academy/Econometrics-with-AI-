LESSON 9.3 Feasible GLS & Transformations

Prais–Winsten, Cochrane–Orcutt & Feasible GLS

In empirical research, the true autocorrelation parameter \(\rho\) is unknown. Feasible Generalized Least Squares (FGLS) solves this by estimating \(\rho\) from initial OLS residuals. Learn how the iterative Cochrane–Orcutt procedure and the observation-preserving Prais–Winsten transformation restore spherical errors in practice.

LEARNING OBJECTIVES
  • Understand why unknown \(\rho\) makes textbook GLS infeasible and motivates Feasible GLS.
  • Trace the sequential workflow from OLS residuals to estimated \(\widehat{\rho}\) and transformed re-estimation.
  • Examine how Cochrane–Orcutt applies the AR(1) transformation for \(t \ge 2\) and drops the first observation.
  • Master the special first-observation transformation \(y_1^* = \sqrt{1-\widehat{\rho}^2}\,y_1\) that retains all data points.
  • Evaluate the source insight on why preserving the first observation avoids finite-sample efficiency loss.
CORE ESTIMATION

1. Feasible GLS for AR(1) Errors

Lesson 9.2 demonstrated that if the autocorrelation parameter \(\rho\) is known, quasi-differencing purges AR(1) serial dependence, leaving spherical innovations. In empirical practice, however, \(\rho\) is almost never known. Feasible Generalized Least Squares (FGLS) operationalizes the procedure by estimating \(\rho\) from sample residuals.

PROCEDURE

FEASIBLE GLS FOR AR(1) ERRORS · Estimating ρ When It Is Unknown

GOAL

Use an estimated autocorrelation parameter \(\widehat{\rho}\) to perform the AR(1) transformation.

1

Step 1: Run Initial OLS

Estimate the original structural regression model by Ordinary Least Squares:

$$y_t = \mathbf{x}_t'\boldsymbol{\beta} + \varepsilon_t \implies \text{obtain } \widehat{\boldsymbol{\beta}}_{\text{OLS}}$$
WHY? We need residuals before we can estimate the unknown autocorrelation parameter. Under strict exogeneity, \(\widehat{\boldsymbol{\beta}}_{\text{OLS}}\) is consistent.
2

Step 2: Compute Residuals

Compute the sample OLS residuals across all observation periods:

$$\widehat{\varepsilon}_t = y_t - \mathbf{x}_t'\widehat{\boldsymbol{\beta}}_{\text{OLS}} \quad \text{for } t = 1, \dots, n$$
WHY? The residuals provide sample information about serial dependence in the disturbances.
3

Step 3: Estimate ρ

Regress the OLS residuals on their own first lag without an intercept:

$$\widehat{\varepsilon}_t \text{ on } \widehat{\varepsilon}_{t-1} \implies \text{obtain } \widehat{\rho} = \frac{\sum_{t=2}^n \widehat{\varepsilon}_t \widehat{\varepsilon}_{t-1}}{\sum_{t=2}^n \widehat{\varepsilon}_{t-1}^2}$$
WHY? Under the AR(1) model, the current disturbance depends on the previous disturbance through \(\rho\).
4

Step 4: Transform the Data

For periods \(t \ge 2\), compute the quasi-differenced variables using the estimated \(\widehat{\rho}\):

$$\begin{aligned} y_t^* &= y_t - \widehat{\rho}\,y_{t-1} \\ \mathbf{x}_t^* &= \mathbf{x}_t - \widehat{\rho}\,\mathbf{x}_{t-1} \end{aligned}$$
WHY? The quasi-difference is designed to remove the AR(1) persistence.
5

Step 5: Re-Estimate

Run OLS on the transformed model to obtain the Feasible Generalized Least Squares estimate:

$$y_t^* = \mathbf{x}_t^{*\prime}\boldsymbol{\beta} + u_t \implies \text{obtain } \widehat{\boldsymbol{\beta}}_{\text{FGLS}}$$
KEY RESULT Unknown \(\rho\) \(\longrightarrow\) estimate \(\widehat{\rho}\) \(\longrightarrow\) transform data \(\longrightarrow\) run OLS on transformed model.

BIG PICTURE

FGLS makes GLS feasible by replacing the unknown autocorrelation parameter with an estimate obtained from the data.

TRANSFORMATION PROCEDURES

2. Prais–Winsten vs. Cochrane–Orcutt

When applying the quasi-differencing transformation to empirical data, the researcher immediately encounters an operational question: how should the very first observation (\(t=1\)) be treated? Two classic procedures provide differing answers.

PROCEDURE 1

Cochrane–Orcutt

Cochrane–Orcutt applies the AR(1) transformation for \(t \ge 2\) and drops the first observation.

Algorithm Steps from Lecture Notes:
  1. Start with OLS on original model.
  2. Obtain sample residuals \(\widehat{\varepsilon}_t\).
  3. Estimate \(\widehat{\rho}\) by regressing \(\widehat{\varepsilon}_t\) on \(\widehat{\varepsilon}_{t-1}\).
  4. Transform \(y\) and \(\mathbf{x}\) via quasi-differencing for \(t \ge 2\).
  5. Re-run the transformed regression while dropping the first observation.
  6. Update \(\widehat{\rho}\) and iterate until convergence.
Observation Strategy: Drops \(t=1\). Effective transformed sample size is \(n - 1\).
PROCEDURE 2

Prais–Winsten

Prais–Winsten retains the first observation by applying a special transformation to \(t=1\).

Prais–Winsten Transformation:
$$\begin{aligned} \text{For } t = 1: \quad & y_1^* = \sqrt{1 - \widehat{\rho}^2}\,y_1, \quad \mathbf{x}_1^* = \sqrt{1 - \widehat{\rho}^2}\,\mathbf{x}_1 \\ \text{For } t \ge 2: \quad & y_t^* = y_t - \widehat{\rho}\,y_{t-1}, \quad \mathbf{x}_t^* = \mathbf{x}_t - \widehat{\rho}\,\mathbf{x}_{t-1} \end{aligned}$$
WHY THIS MATTERS: Prais–Winsten applies a special transformation to the first observation so that it can remain in the transformed sample, retaining all \(n\) observations.
SOURCE TAKEAWAY · PRESERVING THE FIRST OBSERVATION

Prais–Winsten retains the first observation, while Cochrane–Orcutt drops it. In the lecture notes, preserving the first observation is the reason Prais–Winsten is presented as avoiding the efficiency loss associated with discarding that observation.

Feature Cochrane–Orcutt Prais–Winsten
First observation Dropped. Retained using a special transformation (\(\sqrt{1-\widehat{\rho}^2}\)).
For \(t \ge 2\) Uses the AR(1) quasi-difference (\(y_t - \widehat{\rho}y_{t-1}\)). Uses the AR(1) quasi-difference (\(y_t - \widehat{\rho}y_{t-1}\)).
Unknown \(\rho\) Uses estimated \(\widehat{\rho}\) in feasible implementation. Uses estimated \(\widehat{\rho}\) in feasible implementation.
Key distinction Loses first observation (\(n-1\) usable observations). Preserves first observation (\(n\) usable observations).
Source efficiency point Dropping first observation leads to some efficiency loss. Avoids that loss by retaining it.

WHAT YOU ARE SEEING

A simulated AR(1) disturbance path across time. In Original mode, errors follow \(\varepsilon_t = \rho\varepsilon_{t-1} + u_t\) with innovations generated from a fixed deterministic sequence.

WHAT TO NOTICE

With positive \(\rho\), neighboring errors tend to remain on the same side of zero for longer stretches. Shocks persist across adjacent periods instead of jumping randomly.

WHY IT MATTERS

Serial correlation violates the spherical-error assumption underlying conventional OLS variance calculations. Conventional standard errors are incorrect under the maintained AR(1) structure.

ECONOMETRIC INTERPRETATION

Under the lecture assumptions, OLS coefficients may remain unbiased and consistent under strict exogeneity, but conventional standard errors are incorrect.

CONCEPT CHECK

4. Quick Check 9.3

CHECK 9.3 Prais–Winsten vs Cochrane–Orcutt
Question: Why does Prais–Winsten retain more sample information than Cochrane–Orcutt?
HINT: Compare what each procedure does with the first observation.

ANSWER: Cochrane–Orcutt drops the first observation when applying the AR(1) transformation. Prais–Winsten instead applies a special transformation to the first observation and keeps it in the sample.

WHY? The lecture notes emphasize that dropping the first observation causes some efficiency loss. Prais–Winsten avoids discarding that observation.

📋

What You Should Now Understand

  • FGLS replaces the unknown AR(1) parameter \(\rho\) with an estimate \(\widehat{\rho}\).
  • Cochrane–Orcutt transforms observations for \(t \ge 2\) and drops the first observation.
  • Prais–Winsten retains the first observation using a special transformation.
  • Both procedures use AR(1) quasi-differencing for later observations.
  • The lecture notes emphasize that preserving the first observation avoids the efficiency loss associated with dropping it.
