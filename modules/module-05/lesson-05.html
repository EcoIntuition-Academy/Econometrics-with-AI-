LESSON 5.5 Indicator Variables

Binary Dummy Variables

Economic data frequently incorporate qualitative attributes: treatment status, union membership, or geographic locations. Learn how binary indicator variables (\(D_i \in \{0, 1\}\)) allow linear models to capture group-level differences and conditional expectations.

LEARNING OBJECTIVES

  • Define a binary indicator variable taking values \(0\) or \(1\) to partition observations into mutually exclusive states.
  • Derive conditional expectations for the base group (\(\mathbb{E}[y \mid D=0] = \beta_1\)) and coded group (\(\mathbb{E}[y \mid D=1] = \beta_1 + \beta_2\)).
  • Interpret the dummy coefficient \(\beta_2\) as the difference in conditional expectations between the two groups.
  • Test the null hypothesis of group mean equality (\(H_0: \beta_2 = 0\)) while avoiding premature causal interpretations without controls.

1. The Indicator Variable Concept

A dummy variable (also termed an indicator variable) is an artificial binary variable created to represent qualitative or categorical attributes. It partitions observations into two distinct subsets:

FORMAL DEFINITION Binary Indicator Variable
\[ D_i = \begin{cases} 1 & \text{if observation } i \text{ possesses the attribute} \\ 0 & \text{otherwise} \end{cases} \]
COMMON EXAMPLES:
\(\text{union}_i = 1\) Worker belongs to a union; \(0\) if non-union
\(\text{treated}_i = 1\) Subject received a job-training voucher; \(0\) if control
\(\text{male}_i = 1\) Worker is male; \(0\) if female (canonical labor market example)

2. Conditional Expectations and Group Means

Consider the classical benchmark bivariate regression of log wages on a binary indicator \(D_i\): \[ \ln(\text{wage}_i) = \beta_1 + \beta_2 D_i + \varepsilon_i, \quad \mathbb{E}[\varepsilon_i \mid D_i] = 0 \] To uncover the substantive meaning of parameters \(\beta_1\) and \(\beta_2\), evaluate the conditional expectation function for both values of \(D_i\):

BASE / REFERENCE GROUP (\(D = 0\))
\(\mathbb{E}[\ln w \mid D=0] = \beta_1\)

When \(D = 0\), the dummy term vanishes: \(\beta_1 + \beta_2(0) = \beta_1\). The intercept represents the average outcome of the reference group.

CODED GROUP (\(D = 1\))
\(\mathbb{E}[\ln w \mid D=1] = \beta_1 + \beta_2\)

When \(D = 1\), the dummy is active: \(\beta_1 + \beta_2(1) = \beta_1 + \beta_2\). The average outcome is shifted by \(\beta_2\).

GROUP DIFFERENCE
\(\Delta \mathbb{E} = \beta_2\)

Subtracting base from coded: \((\beta_1 + \beta_2) - \beta_1 = \beta_2\). The coefficient \(\beta_2\) is the gap in conditional means!

Methodological Caution

Descriptive Difference vs. Causal Effect

In this simple bivariate regression without controls, \(\hat{\beta}_2\) measures the raw descriptive difference in sample averages. It must not be interpreted as a causal effect. In observational data, groups often differ systematically in education, experience, occupation, or location. In Lesson 5.6, we will control for continuous confounders to address omitted variable bias.

3. Testing the Equality of Group Means

To test whether the two groups have identical expected outcomes in the population, we test whether the difference \(\beta_2\) is zero: \[ H_0: \beta_2 = 0 \quad \text{versus} \quad H_1: \beta_2 \neq 0 \]

Under \(H_0\), the classical \(t\)-statistic is: \[ t = \frac{\hat{\beta}_2}{\operatorname{SE}(\hat{\beta}_2)} \] Remarkably, estimating this simple OLS regression with an intercept and a single dummy regressor yields a \(t\)-statistic mathematically identical to the classical two-sample independent \(t\)-test with pooled variance.

QUICK CHECK Interpreting Binary Indicator Coefficients

An analyst estimates the regression \(\ln(\text{wage}) = 2.40 + 0.25 \cdot \text{union} + e\), where \(\text{union}_i = 1\) if the worker belongs to a labor union and \(0\) otherwise. What is the estimated expected log wage for a non-union worker, and what does the value \(0.25\) represent?

Show Answer & Explanation
ANSWER: Non-union worker expected log wage is \(2.40\). The value \(0.25\) is the estimated difference in average log wage between union and non-union workers in this sample.

DETAILS:
  1. For non-union workers (\(\text{union} = 0\)): \(\mathbb{E}[\ln w \mid \text{union}=0] = 2.40 + 0.25(0) = \mathbf{2.40}\).
  2. For union workers (\(\text{union} = 1\)): \(\mathbb{E}[\ln w \mid \text{union}=1] = 2.40 + 0.25(1) = \mathbf{2.65}\).
  3. The coefficient \(0.25\) shifts the expectation for the coded group: \(2.65 - 2.40 = 0.25\).
TAKEAWAYS

What You Should Now Understand

  • A binary indicator variable takes values in \(\{0, 1\}\) to encode qualitative group membership into regression models.
  • In the model \(y = \beta_1 + \beta_2 D + \varepsilon\), the intercept \(\beta_1\) is the conditional expectation of the base group (\(D = 0\)).
  • The coefficient \(\beta_2\) equals the difference in conditional expectations: \(\mathbb{E}[y \mid D=1] - \mathbb{E}[y \mid D=0]\).
  • Testing \(H_0: \beta_2 = 0\) tests whether group means are equal in the population and is equivalent to a two-sample \(t\)-test.
  • Bivariate dummy coefficients measure raw sample differences; they do not establish causality without controlling for confounding factors.
