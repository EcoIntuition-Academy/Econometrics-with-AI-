LESSON 5.2 Decision Theory

One-Sided Tests, Type II Error & Power

What if economic theory predicts an unambiguous direction—such as schooling increasing wages? Discover one-sided right-tailed hypothesis testing, define Type II error (failing to detect a real effect), and explore how statistical power depends on effect magnitude and sample precision.

LEARNING OBJECTIVES

  • Formulate a directional one-sided right-tailed hypothesis test: \(H_0: \beta_2 \le 0\) vs. \(H_1: \beta_2 > 0\).
  • Identify the standard 5% one-tailed critical value \(t = 1.645\) and compare it against the two-tailed threshold \(\pm 1.96\).
  • Define Type II Error as failing to reject the null when the alternative is true.
  • Define Statistical Power as \(1 - \text{Type II Error Rate}\) (the probability of detecting a real effect).
  • Analyze how effect size (\(\Delta\)) and standard error (\(\operatorname{SE}\)) govern the power of econometric tests.

1. Directional Testing: The One-Sided Right-Tailed Test

In Lesson 5.1, we tested whether \(\beta_2 \neq 0\) in either direction. But in many economic contexts, economic theory predicts a specific sign. For example, human capital theory asserts that schooling cannot diminish earnings.

We formulate a right-tailed test as follows:

Right-Tailed Hypothesis Test
\[H_0: \beta_2 \le 0 \quad \text{versus} \quad H_1: \beta_2 > 0\]
The null hypothesis posits that the coefficient is non-positive; the alternative posits that it is strictly positive.

In a right-tailed test at the \(\alpha = 0.05\) significance level, the entire 5% rejection probability is concentrated in the upper tail:

Key Equation: 5% One-Tailed Critical Value
\[\text{Critical Value: } t_{0.95} = 1.645\]
We reject \(H_0\) if the observed test statistic exceeds \(+1.645\). The upper tail contains the entire \(0.05\) probability area.

2. Comparative Analysis: One-Sided vs. Two-Sided Tests

How does a one-sided test differ from a two-sided test? Let's compare their properties directly:

Two-Sided Test (H₁: β₂ ≠ 0)
  • Rejection Regions: Split into two tails (\(2.5\%\) each).
  • Critical Values: \(\pm 1.96\).
  • Detection: Detects both positive and negative unexpected deviations.
  • Requirement: Default scientific standard in empirical work.
Right-Tailed Test (H₁: β₂ > 0)
  • Rejection Region: Concentrated entirely in the upper tail (\(5.0\%\)).
  • Critical Value: \(+1.645\) (lower threshold to reject).
  • Trade-off: Higher statistical power in the positive direction, but completely blind to negative effects.
  • Requirement: Requires strong, pre-specified theoretical justification.
METHODOLOGICAL CAUTION Methodological Warning

Never choose a one-sided test after inspecting the sample estimate!
If you run a regression, see that \(\hat{\beta}_2 = +1.75\) (which fails to reject two-sided at \(\pm 1.96\)), and then switch to a one-sided test to claim significance at \(1.645\), you are engaging in "p-hacking". Directional tests must be registered before examining the data.

3. Type II Error & Statistical Power

While Type I error is a "false alarm," the opposite failure is a "missed opportunity":

Definition: Type II Error
\[\text{Type II Error } (\beta_{\text{error}}): \text{Failing to reject } H_0 \text{ even though } H_1 \text{ is true}\]
A "false negative": The policy or regressor genuinely affects outcome \(y\) in reality (\(\beta_2 > 0\)), but the sample estimate fails to cross the critical threshold. Note: We write \(\beta_{\text{error}}\) to prevent confusion with the regression coefficient \(\beta_k\).
Definition: Statistical Power
\[\text{Power} = 1 - \beta_{\text{error}} = \Pr(\text{Reject } H_0 \mid H_1 \text{ is True})\]
The probability that an econometric study correctly rejects the null hypothesis when a true effect exists.
True State of Reality Decision: Fail to Reject \(H_0\) Decision: Reject \(H_0\)
\(H_0\) is True Correct Decision
Probability = \(1 - \alpha\) (\(0.95\) at 5% level) 		Type I Error (False Positive)
Probability = \(\alpha\) (\(0.05\) at 5% level)
\(H_0\) is False (\(H_1\) True) Type II Error (False Negative)
Probability = \(\beta_{\text{error}}\) 		Correct Detection (Power)
Probability = \(1 - \beta_{\text{error}}\)

Statistical power depends on two key empirical factors:

1. Effect Size (\(\Delta\))

Larger true population effects shift the \(H_1\) distribution further to the right, moving more probability mass past the critical boundary and increasing power.

2. Estimation Precision (\(\operatorname{SE}\))

Larger sample sizes (\(n\)) reduce the standard error \(\operatorname{SE} = \frac{\sigma}{\sqrt{n}}\), tightening both distributions and drastically shrinking the Type II error region.

WHY IT MATTERS

If an empirical study has low power (e.g. \(35\%\)), there is a \(65\%\) probability that the researcher will fail to detect an effective policy intervention purely due to noisy, underpowered data.

ECONOMETRIC INTERPRETATION

Pre-analysis power calculations ensure that sample size \(n\) is large enough before spending millions on field experiments or survey data collection.

QUICK CHECK Right-Tailed Critical Value

In a right-tailed test of \(H_0: \beta_2 \le 0\) vs \(H_1: \beta_2 > 0\) at the 5% level, an econometrician calculates \(t = 1.78\). What is the critical value from the source, and what is the test conclusion? What would the conclusion have been if a two-tailed test was used instead?

Show Answer & Explanation
ANSWER: Critical value: \(1.645\). Right-tailed conclusion: REJECT \(H_0\). Two-tailed conclusion: FAIL TO REJECT \(H_0\).

WHY?
  1. For a right-tailed test at \(\alpha = 0.05\), the critical value is \(1.645\). Since \(1.78 > 1.645\), we reject \(H_0\) at the 5% level.
  2. For a two-tailed test at \(\alpha = 0.05\), the critical values are \(\pm 1.96\). Because \(1.78 \le 1.96\), a two-tailed test fails to reject \(H_0\). This clearly shows how directional tests place all 5% probability in one tail, requiring a smaller positive estimate to achieve significance.
TAKEAWAYS

What You Should Now Understand

  • A right-tailed test tests \(H_0: \beta_2 \le 0\) against \(H_1: \beta_2 > 0\), placing the entire 5% rejection region in the upper tail with critical value \(t_{0.95} = 1.645\).
  • One-sided tests have higher power in the hypothesized direction, but cannot detect unexpected reversals in the opposite direction.
  • Type II Error is failing to reject \(H_0\) when the alternative is true.
  • Statistical Power is \(1 - \text{Type II Error Rate}\): the probability of correctly identifying a real effect.
  • Power increases when the true effect size is larger and when standard errors are smaller (e.g., through larger sample sizes).
