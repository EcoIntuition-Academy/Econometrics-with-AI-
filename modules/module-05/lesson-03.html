LESSON 5.3 Matrix Hypothesis Testing

Testing Linear Restrictions: \(R\beta = q\)

A single test such as \(\beta_2 = 0\) is just one specific linear restriction. In empirical economics, hypotheses often involve sums of coefficients, equality across parameters, or multiple simultaneous constraints. Discover how matrix notation unifies all linear hypotheses under \(H_0: R\beta = q\).

LEARNING OBJECTIVES

  • Express linear parameter restrictions in matrix notation as \(H_0: R\beta = q\) versus \(H_1: R\beta \neq q\).
  • Identify the exact mathematical dimensions of \(R\) (\(J \times K\)), \(\beta\) (\(K \times 1\)), \(q\) (\(J \times 1\)), and the discrepancy vector \(R\beta - q\) (\(J \times 1\)).
  • Explain why \(J\) counts the number of restrictions being tested rather than the number of regressors \(K\).
  • Construct restriction matrices \(R\) and vectors \(q\) for single zero coefficients, parameter sums, and simultaneous equality conditions.

1. The \(R\beta = q\) Framework

In Lessons 5.1 and 5.2, we focused on testing single regression parameters, such as \(H_0: \beta_2 = 0\). However, economic theories frequently yield more intricate predictions:

  • Constant Returns to Scale: In a Cobb-Douglas production function, testing whether the capital and labor elasticities sum to one (\(\beta_2 + \beta_3 = 1\)).
  • Equal Response Across Groups: Testing whether the return to schooling is identical in two sectors (\(\beta_3 = \beta_4\), or \(\beta_3 - \beta_4 = 0\)).
  • Joint Insignificance: Testing whether an entire block of policy indicators has zero combined effect (\(\beta_2 = 0 \text{ and } \beta_3 = 0\)).
KEY DEFINITION General Linear Restriction in Matrix Form
\[ H_0: R\beta = q \quad \text{versus} \quad H_1: R\beta \neq q \]
WHERE:
\(R\) \(J \times K\) restriction matrix specifying linear combinations of parameters
\(\beta\) \(K \times 1\) vector containing all unknown population regression parameters
\(q\) \(J \times 1\) vector of hypothesized constants under the null
\(R\beta - q\) \(J \times 1\) restriction discrepancy vector; equals \(\mathbf{0}\) if \(H_0\) holds true

2. Matrix Dimensions and Precision

Dimensional precision prevents indexing errors and clarifies the algebra. Every element of the restriction equation has an exact mathematical dimension:

\(R\) : \(J \times K\)
Restriction Matrix

Rows = \(J\) restrictions
Columns = \(K\) parameters

\(\beta\) : \(K \times 1\)
Parameter Vector

All \(K\) coefficients (including the intercept \(\beta_1\))

\(q\) : \(J \times 1\)
Hypothesized Constants

Hypothesized values for each restriction (often \(\mathbf{0}\))

\(R\beta - q\) : \(J \times 1\)
Discrepancy Vector

\((J \times K)(K \times 1) - (J \times 1) = J \times 1\)

Crucial Distinction

Do Not Confuse \(J\) with \(K\)

Common Mistake: Confusing the number of regressors \(K\) with the number of restrictions \(J\).
Correction: \(K\) is the total number of parameters in the model. \(J\) is the number of linear hypotheses being tested. \(J\) equals the number of rows in \(R\) and \(q\). For valid tests, we require \(J \le K\).

3. Three Classic Worked Examples (\(K = 5\))

Consider a multiple regression model with \(K = 5\) coefficients: \[ y = \beta_1 + \beta_2 x_2 + \beta_3 x_3 + \beta_4 x_4 + \beta_5 x_5 + \varepsilon \] where \(\beta = \begin{bmatrix} \beta_1 & \beta_2 & \beta_3 & \beta_4 & \beta_5 \end{bmatrix}'\). Here is how \(R\) and \(q\) are constructed for three canonical econometric tests:

WORKED EXAMPLE 1 Single Parameter Test: \(H_0: \beta_2 = 0\)

Goal: Formulate the classic single-parameter null hypothesis in matrix form with \(K = 5\) and \(J = 1\).

\[ R = \begin{bmatrix} 0 & 1 & 0 & 0 & 0 \end{bmatrix}_{1 \times 5}, \quad q = [0]_{1 \times 1} \]

Apply \(R\): Matrix multiplication isolates \(\beta_2\): \[ R\beta = 0\cdot\beta_1 + 1\cdot\beta_2 + 0\cdot\beta_3 + 0\cdot\beta_4 + 0\cdot\beta_5 = \beta_2 \]

Restriction Discrepancy: \[ R\beta - q = \beta_2 - 0 = \beta_2 \] Under \(H_0\), the discrepancy must equal zero: \(R\beta - q = 0\).

WORKED EXAMPLE 2 Sum of Parameters: \(H_0: \beta_2 + \beta_3 = 1\)

Goal: Test whether two coefficients sum to a specified constant (e.g., constant returns to scale).

\[ R = \begin{bmatrix} 0 & 1 & 1 & 0 & 0 \end{bmatrix}_{1 \times 5}, \quad q = [1]_{1 \times 1} \]

Apply \(R\): Weights \(1\) on \(\beta_2\) and \(1\) on \(\beta_3\), with \(0\) elsewhere: \[ R\beta = 1\cdot\beta_2 + 1\cdot\beta_3 = \beta_2 + \beta_3 \]

Restriction Discrepancy: \[ R\beta - q = (\beta_2 + \beta_3) - 1 \] Under \(H_0\), \(R\beta - q = 0\). Notice that here \(q\) is a non-zero constant vector!

WORKED EXAMPLE 3 Simultaneous Restrictions: \(H_0: \beta_2 = 0 \text{ and } \beta_3 = \beta_4\)

Goal: Simultaneously test that \(\beta_2 = 0\) AND that \(\beta_3 = \beta_4\) (rewritten as \(\beta_3 - \beta_4 = 0\)). Here \(J = 2\).

\[ R = \begin{bmatrix} 0 & 1 & 0 & 0 & 0 \\ 0 & 0 & 1 & -1 & 0 \end{bmatrix}_{2 \times 5}, \quad q = \begin{bmatrix} 0 \\ 0 \end{bmatrix}_{2 \times 1} \]

Apply \(R\): Row 1 isolates \(\beta_2\); Row 2 calculates \(\beta_3 - \beta_4\): \[ R\beta = \begin{bmatrix} \beta_2 \\ \beta_3 - \beta_4 \end{bmatrix}_{2 \times 1} \]

Restriction Discrepancy: \[ R\beta - q = \begin{bmatrix} \beta_2 - 0 \\ (\beta_3 - \beta_4) - 0 \end{bmatrix} = \begin{bmatrix} \beta_2 \\ \beta_3 - \beta_4 \end{bmatrix}_{2 \times 1} \] Both restrictions must hold simultaneously under the null hypothesis.

WHAT YOU ARE SEEING

The explicit matrix multiplication \(R \cdot \beta\) and vector subtraction of \(q\), producing the exact algebraic discrepancy vector for each chosen hypothesis.

WHAT TO NOTICE

In Example 3, Row 2 places a \(+1\) on \(\beta_3\) and a \(-1\) on \(\beta_4\). This directly computes the difference \(\beta_3 - \beta_4\), evaluating equality of slopes.

WHY IT MATTERS

The matrix formulation \(R\beta = q\) unifies all linear tests, enabling software algorithms to test arbitrarily complex econometric restrictions with one standardized formula.

ECONOMETRIC INTERPRETATION

The sample estimate \(R\hat{\beta} - q\) is the empirical discrepancy. If this discrepancy is near zero, the sample data support the restriction; if far from zero, the restriction is rejected.

QUICK CHECK Constructing Linear Restriction Matrices

Consider the model with \(K = 4\) parameters: \(y = \beta_1 + \beta_2 x_2 + \beta_3 x_3 + \beta_4 x_4 + \varepsilon\). Suppose economic theory predicts that both \(\beta_2 = 0\) and \(\beta_3 + \beta_4 = 2\). What are the dimensions of \(R\) and \(q\), and what is the second row of \(R\)?

Show Answer & Explanation
ANSWER: \(R\) is \(2 \times 4\), \(q\) is \(2 \times 1\), and the second row of \(R\) is \(\begin{bmatrix} 0 & 0 & 1 & 1 \end{bmatrix}\).

WHY?
  1. There are \(J = 2\) simultaneous restrictions and \(K = 4\) parameters. Therefore, \(R\) is \(J \times K = 2 \times 4\) and \(q\) is \(J \times 1 = 2 \times 1\).
  2. Row 1 tests \(\beta_2 = 0 \implies \begin{bmatrix} 0 & 1 & 0 & 0 \end{bmatrix}\) with constant \(0\).
  3. Row 2 tests \(\beta_3 + \beta_4 = 2 \implies \begin{bmatrix} 0 & 0 & 1 & 1 \end{bmatrix}\) with constant \(2\).
  4. Vector \(q = \begin{bmatrix} 0 \\ 2 \end{bmatrix}\). The resulting discrepancy is \(\begin{bmatrix} \beta_2 \\ \beta_3 + \beta_4 - 2 \end{bmatrix}_{2 \times 1}\).
TAKEAWAYS

What You Should Now Understand

  • The matrix equation \(H_0: R\beta = q\) unifies single \(t\)-tests, parameter sums, slope equality, and joint insignificance into one general framework.
  • The restriction matrix \(R\) is \(J \times K\), where \(J\) is the number of restrictions and \(K\) is the total number of parameters.
  • The parameter vector \(\beta\) is \(K \times 1\) and the hypothesized constants vector \(q\) is \(J \times 1\).
  • The discrepancy vector \(R\beta - q\) has dimension \(J \times 1\). Under \(H_0\), its true population value is \(\mathbf{0}\).
  • In finite samples, the estimated discrepancy \(R\hat{\beta} - q\) rarely equals zero exactly. In Lesson 5.4, we will learn how to scale this discrepancy by its covariance matrix using Wald and \(F\) tests.
