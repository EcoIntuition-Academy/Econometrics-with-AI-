LESSON 5.1 Inference Foundations

Hypothesis Testing & Type I Error

How do economists decide whether an empirical coefficient reflects a genuine real-world relationship or merely random sampling noise? Discover how hypothesis tests are formulated as coefficient restrictions, understand how Type I error is controlled by significance level \(\alpha\), and explore two-tailed critical rejection regions.

LEARNING OBJECTIVES

  • Set up null and alternative hypotheses in a multiple regression model (\(H_0: \beta_2 = 0\) vs. \(H_1: \beta_2 \neq 0\)).
  • Follow the step-by-step logic of hypothesis testing: from provisional assumption to decision.
  • Define Type I Error as the false rejection of a true null hypothesis, controlled by significance level \(\alpha\).
  • Partition the rejection probability in a two-tailed test at \(\alpha = 0.05\) (\(2.5\%\) in each tail with critical values \(\pm 1.96\)).
  • Adhere strictly to professional econometric terminology: "Reject \(H_0\)" vs. "Fail to Reject \(H_0\)" (never "Accept \(H_0\)").

1. The Multiple Regression Framework

Consider the classical multiple linear regression model with five explanatory variables:

Context Regression Model
\[y = \beta_1 + \beta_2 x_2 + \beta_3 x_3 + \beta_4 x_4 + \beta_5 x_5 + \varepsilon\]
Where \(\beta_1\) is the intercept and \(\beta_2, \dots, \beta_5\) are the partial regression slopes.

In applied economics, the most frequent statistical question is whether a specific regressor \(x_2\) has any true population effect on outcome \(y\), holding other regressors constant. We formulate this as a restriction on the coefficient:

Null & Alternative Hypotheses for β₂
\[H_0: \beta_2 = 0 \quad \text{versus} \quad H_1: \beta_2 \neq 0\]
Null Hypothesis (\(H_0\)): The regressor \(x_2\) has zero population effect.
Alternative Hypothesis (\(H_1\)): The regressor \(x_2\) has a nonzero population effect (two-sided).

2. Intuition First: The 5-Step Logic of a Hypothesis Test

A hypothesis test is an evidentiary trial. We do not set out to "prove" the null hypothesis; we temporarily assume it is true and evaluate whether the empirical evidence is sufficiently contradictory to warrant its rejection.

The Universal Hypothesis Testing Workflow

STEP 1 PROVISIONALLY ASSUME \(H_0\): Assume the null restriction \(\beta_2 = 0\) holds in the population.
STEP 2 DERIVE NULL DISTRIBUTION: Determine the probability distribution of the estimator \(\hat{\beta}_2\) under \(H_0\).
STEP 3 OBSERVE TEST STATISTIC: Calculate the standardized distance \(t = \frac{\hat{\beta}_2 - 0}{\operatorname{SE}(\hat{\beta}_2)}\) from sample data.
STEP 4 COMPARE WITH CRITICAL REGION: Check whether the test statistic falls into the extreme rejection tails (\(|t| > 1.96\)).
STEP 5 DRAW DECISION: Conclude either REJECT \(H_0\) or FAIL TO REJECT \(H_0\).

3. Type I Error: Controlling the False Alarm Rate

Because sample estimators fluctuate randomly from dataset to dataset, we could mistakenly observe a large estimate \(\hat{\beta}_2\) purely by random chance, even when the true population coefficient is exactly zero.

Definition: Type I Error
\[\Pr(\text{Type I Error}) = \Pr(\text{Reject } H_0 \mid H_0 \text{ is True}) = \alpha\]
A Type I Error occurs when we reject the null hypothesis when it is actually true (a "false positive" or "false alarm"). It is directly controlled by the significance level \(\alpha\).

The most common convention in economics is \(\alpha = 0.05\) (5% significance level). This guarantees that:

Intuitive Interpretation

"If \(\beta_2\) truly equals 0, then we should only reject \(H_0\) 5% of the time. This is controlled by selecting appropriate critical values."

The Two-Tailed Partition at α = 0.05

Because the alternative hypothesis \(H_1: \beta_2 \neq 0\) is two-sided (the coefficient could be either positive or negative), the 5% error probability is split symmetrically across both tails:

  • Lower Critical Value: \(-1.96\) (cuts off the lower \(2.5\%\) area, \(\alpha / 2 = 0.025\)).
  • Upper Critical Value: \(+1.96\) (cuts off the upper \(2.5\%\) area, \(\alpha / 2 = 0.025\)).
  • Non-Rejection Region: The central \(95\%\) interval \([-1.96, +1.96]\) where observed estimates are statistically consistent with \(H_0\).

WHY IT MATTERS

By fixing the critical boundaries at \(\pm 1.96\), we ensure that if the null hypothesis is truly correct, we will falsely reject it no more than 5 times out of 100 repeated samples.

ECONOMETRIC INTERPRETATION

Observing a \(t\)-statistic of \(+2.10\) yields a \(p\)-value of \(0.036\). Because \(0.036 < 0.05\), observing such an extreme estimate purely by sampling fluke is too unlikely, so we conclude that \(\beta_2\) is statistically significantly different from zero.

5. Crucial Econometric Caution: Reject vs. Fail to Reject

In scientific econometrics, language precision is paramount. We NEVER conclude that we "accept" the null hypothesis.

METHODOLOGICAL CAUTION Common Mistake: "Accepting" the Null

"Because |t| ≤ 1.96, we accept H₀ and conclude that the true coefficient is definitely zero."
Correction: Failing to reject \(H_0\) does NOT prove that \(\beta_2 = 0\). It simply means that our sample did not provide strong enough empirical evidence to rule out zero. The true parameter could be \(0.04\) or \(-0.02\), but our dataset had too small a sample size or too high a variance to detect it.

Always state: "We fail to reject \(H_0\) at the 5% significance level."

QUICK CHECK Type I Error Rate

If a researcher conducts a two-tailed test using \(\alpha = 0.05\) on 100 independent regressions where the null hypothesis \(H_0: \beta_k = 0\) is strictly true in every single case, on average how many of these regressions will falsely report a "statistically significant" result?

Show Answer & Explanation
ANSWER: Exactly 5 regressions on average.

WHY?
  1. By definition, the significance level \(\alpha = 0.05\) sets the exact probability of committing a Type I error under the null: \(\Pr(\text{Reject } H_0 \mid H_0 \text{ true}) = 0.05\).
  2. Out of 100 true null hypotheses, the expected number of false rejections is: \(100 \times 0.05 = 5\).
  3. This illustrates why testing dozens of variables simultaneously without adjusting for multiple testing leads to spurious discoveries!
TAKEAWAYS

What You Should Now Understand

  • A hypothesis test examines whether sample estimates are statistically incompatible with a restriction imposed under \(H_0: \beta_2 = 0\).
  • The testing sequence follows five steps: provisionally assume \(H_0 \to\) derive the null distribution \(\to\) compute the test statistic \(\to\) compare with critical values \(\to\) decide.
  • Type I error is the probability of falsely rejecting a true null hypothesis, which is controlled directly by the significance level \(\alpha\).
  • For a two-tailed test at \(\alpha = 0.05\), the critical values are \(\pm 1.96\), with \(0.025\) probability area in each tail.
  • Failing to reject \(H_0\) reflects an absence of conclusive evidence against zero, not proof that the parameter is exactly zero. We never "accept" \(H_0\).
