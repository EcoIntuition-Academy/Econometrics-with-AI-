LESSON 5.6 Multiple Regressors & Geometry

Controls, Categories & Reference Groups

Combining binary indicators with continuous controls shifts regression lines in parallel. Explore the geometry of parallel regression lines, the \(m-1\) rule for categorical variables, the omitted reference group, and how to avoid the lethal Dummy Variable Trap.

LEARNING OBJECTIVES

  • Understand the parallel-lines geometry created by adding an additive dummy variable to a continuous regressor.
  • Correctly state that \(\beta_2\) is the model-implied group difference holding education fixed (ceteris paribus).
  • Implement sets of dummy indicators for \(m\) mutually exclusive categories by omitting exactly one reference group.
  • Diagnose and avoid the Dummy Variable Trap caused by perfect multicollinearity between all category dummies and the intercept.

1. Continuous Controls & Parallel Regression Lines

In Lesson 5.5, the bivariate dummy regression captured only the unadjusted difference between two group averages. To control for observable confounders, consider adding a continuous covariate such as years of education (\(x_i\)): \[ \ln(\text{wage}_i) = \beta_1 + \beta_2 D_i + \beta_3 x_i + \varepsilon_i \] Evaluating the population conditional expectation function for both groups reveals two distinct regression lines:

GEOMETRIC FORMULATION Two Parallel Regression Lines
\[\begin{aligned} \text{For } D_i = 0: \quad &\mathbb{E}[y \mid D=0, x] = \beta_1 + \beta_3 x \\ \text{For } D_i = 1: \quad &\mathbb{E}[y \mid D=1, x] = (\beta_1 + \beta_2) + \beta_3 x \end{aligned}\]
KEY PROPERTIES:
Same Slope (\(\beta_3\)) Because no interaction term (\(D_i \cdot x_i\)) is included, both lines have identical slope \(\beta_3\)
Vertical Shift (\(\beta_2\)) The dummy variable creates a parallel vertical shift of \(\beta_2\) at every value of \(x\)
Strict Phrasing Requirement

Ceteris Paribus Interpretation

Do NOT say: “\(\beta_2\) is simply the raw wage gap.”
Correct Phrasing: \(\beta_2\) is the model-implied difference between the groups holding the continuous covariate \(x\) fixed.

An additive dummy variable shifts the regression intercept without tilting the slope. It models level differences between groups while assuming common responsiveness to \(x\).

ECONOMETRIC INTERPRETATION

At any given education level, workers in group 1 are predicted to earn \(\beta_2\) log units more than workers in group 0 with identical schooling.

3. Categorical Attributes and the \(m - 1\) Rule

Many economic variables have more than two qualitative outcomes—such as regions, industries, or education levels. Suppose a categorical variable has \(m\) mutually exclusive and exhaustive categories:

STRUCTURAL RULE The \(m - 1\) Dummy Rule with Intercept
\[ y_i = \beta_1 + \beta_2 D_{2i} + \beta_3 D_{3i} + \dots + \beta_m D_{mi} + \varepsilon_i \]
INTERPRETATION:
Reference Group (\(D_1\)) Omitted category whose expected outcome is captured entirely by the intercept \(\beta_1\)
Dummy Coefficients (\(\beta_j\)) Each \(\beta_j\) measures the expected outcome difference between category \(j\) and the reference group

Empirical Example: Regional Housing (\(m = 3\) Categories)

Consider 3 regions: North, Central, and South. Choose North as the omitted reference group:

North (Reference):
\(\mathbb{E}[y \mid \text{North}] = \beta_1\)
Central:
\(\mathbb{E}[y \mid \text{Central}] = \beta_1 + \beta_2\)
South:
\(\mathbb{E}[y \mid \text{South}] = \beta_1 + \beta_3\)

Changing the omitted reference category changes the numerical values and interpretation of individual dummy coefficients, but leaves the fitted values \(\hat{y}_i\) and overall \(R^2\) identical!

4. The Dummy Variable Trap vs. No-Intercept Model

What happens if a researcher includes an intercept \(\beta_1\) and all \(m\) category dummies simultaneously?

Severe Pitfall

The Dummy Variable Trap: Perfect Multicollinearity

Because every observation belongs to exactly one category: \[ \sum_{j=1}^m D_{ji} = D_{1i} + D_{2i} + \dots + D_{mi} = 1 = x_{1i} \quad \text{for all } i \] The sum of all \(m\) indicator columns is an exact linear replica of the constant vector \(\mathbf{1}\).

This creates perfect multicollinearity: the data matrix \(X\) lacks full column rank (\(\operatorname{rank}(X) < K\)), \(X'X\) is non-invertible, and OLS software cannot compute unique estimates.

Alternative Parameterization

The No-Intercept Model

If the intercept is deliberately omitted, all \(m\) dummies can be included: \[ y_i = \gamma_1 D_{1i} + \gamma_2 D_{2i} + \dots + \gamma_m D_{mi} + \varepsilon_i \] Here, each coefficient \(\gamma_j\) directly estimates the sample mean of group \(j\).

QUICK CHECK The \(m - 1\) Rule & Multicollinearity

A researcher estimates household expenditure across four education tiers: High School, Bachelor's, Master's, and Doctorate. The regression includes an intercept and all 4 education dummy variables. Why does the regression fail, and how should it be fixed?

Show Answer & Explanation
ANSWER: The regression fails due to the Dummy Variable Trap (perfect multicollinearity).

EXPLANATION & REMEDY:
  1. Because categories are exhaustive, \(D_1 + D_2 + D_3 + D_4 = 1\) for every observation, duplicating the constant intercept column and making \(X'X\) singular.
  2. Standard Fix: Keep the intercept and omit one reference category (e.g., High School), leaving \(4 - 1 = 3\) dummies.
  3. Alternative Fix: Drop the intercept and include all 4 dummies, where each coefficient directly estimates the average expenditure of that education tier.
TAKEAWAYS

What You Should Now Understand

  • Adding an indicator variable to a continuous regressor shifts the regression line vertically by \(\beta_2\) while preserving a common slope \(\beta_3\).
  • The dummy coefficient \(\beta_2\) is the difference between group conditional expectations holding continuous covariates constant.
  • For \(m\) exhaustive qualitative categories with an intercept, exactly \(m - 1\) dummy variables must be included.
  • Including all \(m\) indicators alongside an intercept triggers the Dummy Variable Trap (perfect multicollinearity).
  • The reference category choice determines the baseline, but does not alter fitted values or model goodness-of-fit.
