LESSON 3.6 Efficiency & Estimation

Gauss–Markov, BLUE & Estimating Error Variance

Discover why OLS achieves the minimum variance among all linear unbiased estimators, trace the matrix decomposition of an arbitrary competitor \(\tilde{\beta} = Cy\), and see why \(\mathbb{E}[e'e \mid X] = \sigma^2(n - k)\) demands the degrees-of-freedom divisor \(n - k\) to obtain the unbiased error variance estimator \(s^2\).

🎯 Learning Objectives

  • State the Gauss–Markov theorem and define each letter of the B-L-U-E acronym.
  • Set up an arbitrary alternative linear estimator \(\tilde{\beta} = Cy\) and prove that unbiasedness requires \(CX = I_k\).
  • Follow the step-by-step Gauss–Markov variance decomposition: \(\operatorname{Var}(\tilde{\beta} \mid X) = \operatorname{Var}(\hat{\beta} \mid X) + \sigma^2 DD'\).
  • Explain why the positive semi-definiteness of \(DD'\) proves that OLS has minimal sampling variance among all linear unbiased competitors.
  • Prove why the naive residual variance estimator \(\frac{1}{n}e'e\) is downward biased and derive the unbiased estimator \(s^2 = \frac{e'e}{n - k}\).

1. The Gauss–Markov Theorem: BLUE

Under the Classical Linear Regression Model assumptions (linearity, strict exogeneity, full rank, and spherical homoskedastic errors), the Gauss–Markov theorem provides the primary theoretical justification for selecting OLS:

👑 The Gauss–Markov Theorem

Under Assumptions A1–A4, the Ordinary Least Squares estimator \(\hat{\beta} = (X'X)^{-1}X'y\) is the Best Linear Unbiased Estimator (BLUE) of \(\beta\).

B
BEST

Achieves the minimum sampling variance (maximum precision) among all unbiased competitors in the linear class. For any linear combination \(c'\hat{\beta}\), its variance is strictly no larger than \(c'\tilde{\beta}\).

L
LINEAR

The estimator is a linear function of the dependent variable vector: \(\hat{\beta} = Ay\) where the weighting matrix is \(A = (X'X)^{-1}X'\).

U
UNBIASED

Centered exactly on the true population parameter: \(\mathbb{E}[\hat{\beta} \mid X] = \beta\). On average across hypothetical repeated samples, it produces zero systematic estimation error.

E
ESTIMATOR

A deterministic mathematical rule and function that maps any observable sample data \((y, X)\) into a parameter estimate vector.

📌 NOTATION NOTE: OLS ESTIMATE \(\hat{\beta}\) VS COMPETITOR \(\tilde{\beta}\)

The source notes write the competitor estimator as \(b_0\) and OLS as \(b\). For website consistency across all modules, we denote the OLS estimator as \(\hat{\beta}\) and the alternative linear competitor as \(\tilde{\beta}\). We reserve \(b\) strictly for generic candidate coefficient vectors in optimization objectives.

2. Matrix Proof: Comparing OLS with Competitor \(\tilde{\beta} = Cy\)

What is this section about? We prove that any alternative linear estimator that achieves unbiasedness must have a sampling variance-covariance matrix equal to the OLS variance plus a positive semi-definite matrix, meaning its variance cannot be smaller than OLS.

DERIVATION JOURNEY

Gauss–Markov Variance Minimality Proof

WHAT ARE WE TRYING TO SHOW?

Prove that for any arbitrary linear unbiased estimator \(\tilde{\beta} = Cy\), its variance-covariance matrix decomposes into \(\operatorname{Var}(\tilde{\beta} \mid X) = \operatorname{Var}(\hat{\beta} \mid X) + \sigma^2 DD'\), where \(\sigma^2 DD'\) is non-negative definite. This establishes that OLS has the minimum variance in the linear unbiased class.

1

Define the Alternative Linear Estimator

Let \(C\) be an arbitrary \(k \times n\) constant matrix (conditional on \(X\)). Write the alternative estimator as a linear combination of outcomes \(y\):

$$\tilde{\beta} = Cy = C(X\beta + \varepsilon) = CX\beta + C\varepsilon$$
WHY THIS STEP? Any estimator that is linear in \(y\) can be represented by a weighting matrix \(C\).
2

Impose the Unbiasedness Condition

Take the expectation conditional on \(X\), using strict exogeneity \(\mathbb{E}[\varepsilon \mid X] = \mathbf{0}\):

$$\mathbb{E}[\tilde{\beta} \mid X] = \mathbb{E}[CX\beta + C\varepsilon \mid X] = CX\beta + C\mathbf{0} = CX\beta$$

For \(\tilde{\beta}\) to be unbiased (\(\mathbb{E}[\tilde{\beta} \mid X] = \beta\)) for any true vector \(\beta\), the weighting matrix must satisfy:

$$CX = I_k$$
WHY THIS STEP? Without \(CX = I_k\), the estimator would suffer from systematic estimation bias.
3

Compute the Variance-Covariance Matrix of \(\tilde{\beta}\)

Since \(\tilde{\beta} - \beta = C\varepsilon\), the variance conditional on \(X\) under spherical errors \(\operatorname{Var}(\varepsilon \mid X) = \sigma^2 I_n\) is:

$$\operatorname{Var}(\tilde{\beta} \mid X) = C \operatorname{Var}(\varepsilon \mid X) C' = C(\sigma^2 I_n)C' = \sigma^2 CC'$$
WHY THIS STEP? Applies the standard variance-of-linear-transformation rule \(\operatorname{Var}(Ay) = A\operatorname{Var}(y)A'\).
4

Decompose \(C\) into OLS Weights Plus a Departure Matrix \(D\)

Define the difference matrix \(D = C - (X'X)^{-1}X'\), so that \(C = (X'X)^{-1}X' + D\). Multiply both sides on the right by \(X\):

$$DX = \left[C - (X'X)^{-1}X'\right]X = CX - (X'X)^{-1}(X'X) = I_k - I_k = \mathbf{0}$$
WHY THIS STEP? This orthogonality property \(DX = \mathbf{0}\) is the mathematical fulcrum of the proof: any departure from OLS must be orthogonal to the regressor matrix \(X\) to preserve unbiasedness.
5

Expand the Matrix Product \(CC'\)

Substitute \(C = (X'X)^{-1}X' + D\) into \(CC'\):

$$CC' = \left[(X'X)^{-1}X' + D\right]\left[(X'X)^{-1}X' + D\right]' = (X'X)^{-1}X'X(X'X)^{-1} + (X'X)^{-1}X'D' + DX(X'X)^{-1} + DD'$$
WHY THIS STEP? FOIL expansion of the matrix product reveals the OLS kernel, the departure kernel, and the cross-product terms.
6

Cross-Product Terms Vanish Identically

Because \(DX = \mathbf{0}\), taking transposes gives \(X'D' = (DX)' = \mathbf{0}' = \mathbf{0}\). Thus the cross-product terms drop out:

$$(X'X)^{-1}X'D' = \mathbf{0} \quad \text{and} \quad DX(X'X)^{-1} = \mathbf{0}$$

The product simplifies cleanly to:

$$CC' = (X'X)^{-1} + DD'$$
WHY THIS STEP? Unbiasedness eliminates any covariance between the OLS estimator and the departure component \(Dy\).
7

Conclude Gauss–Markov Optimality

Multiply by \(\sigma^2\) to obtain the fundamental variance comparison:

$$\operatorname{Var}(\tilde{\beta} \mid X) = \sigma^2(X'X)^{-1} + \sigma^2 DD' = \operatorname{Var}(\hat{\beta} \mid X) + \sigma^2 DD'$$

For any non-zero vector \(a \in \mathbb{R}^k\), the quadratic form satisfies \(a'(DD')a = (D'a)'(D'a) = \|D'a\|^2 \ge 0\). Thus:

$$\operatorname{Var}(a'\tilde{\beta} \mid X) \ge \operatorname{Var}(a'\hat{\beta} \mid X)$$
WHY THIS STEP? Because \(DD'\) is positive semi-definite, no linear unbiased competitor can achieve a lower sampling variance than OLS for any linear combination of coefficients.
💡 BIG PICTURE: WHAT DID WE ACTUALLY PROVE?

The Gauss–Markov theorem does NOT claim that OLS is the best estimator among every conceivable estimator in the universe. Nonlinear estimators (or biased shrinkage estimators like Ridge regression) may achieve lower mean squared error. What Gauss–Markov proves is that within the class of linear unbiased estimators, OLS achieves the theoretical minimum sampling variance. Any linear unbiased alternative has variance equal to OLS variance plus an unavoidable penalty \(\sigma^2 DD' \ge \mathbf{0}\).

KEY EQUATION Gauss–Markov Variance Decomposition
$$\operatorname{Var}(\tilde{\beta} \mid X) = \operatorname{Var}(\hat{\beta} \mid X) + \sigma^2 DD'$$
WHERE
\(\sigma^2 DD'\)
Variance Penalty Matrix: Additional sampling variance incurred by choosing any linear weighting matrix \(C\) other than OLS.
\(DD' \ge \mathbf{0}\)
Positive Semi-Definite: For any vector \(a\), \(a'(DD')a = \|D'a\|^2 \ge 0\).
\(\operatorname{Var}(\tilde{\beta}) \ge \operatorname{Var}(\hat{\beta})\)
Loewner Matrix Order: Every linear combination of \(\tilde{\beta}\) has variance at least as large as the OLS combination.
\(D = \mathbf{0} \iff \tilde{\beta} = \hat{\beta}\)
Uniqueness: OLS is the unique linear unbiased estimator achieving the minimum variance bound.
📚 Source Academic Reference

Hansen, Bruce E. (2022). "A Modern Gauss–Markov Theorem." Econometrica, 90(3), 1283–1294. Hansen demonstrates that the Gauss–Markov theorem holds under weaker conditions than historically assumed, reinforcing the optimality of OLS across broad functional classes.

3. Estimating Error Variance: Why (1/n) e'e is Downward Biased

In practice, the population disturbance variance \(\sigma^2\) is unknown. A natural candidate would be the average of squared sample residuals: \(\frac{1}{n}\sum_{i=1}^n e_i^2 = \frac{1}{n}e'e\). However, that naive estimator is systematically biased.

⚠️ The Downward Bias of Naive Residual Variance

The naive estimator \(\frac{1}{n}e'e\) is downward biased: $$\mathbb{E}\left[\frac{1}{n}e'e \;\middle|\; X\right] = \frac{n - k}{n}\sigma^2 < \sigma^2 \quad (\text{for } k > 0)$$ Because OLS specifically minimizes the sum of squared residuals over the sample, the residuals \(e_i\) are mechanically tighter around the regression plane than the true population disturbances \(\varepsilon_i\).

DERIVATION JOURNEY

Expectation of Residual Sum of Squares \(\mathbb{E}[e'e \mid X]\)

WHAT ARE WE TRYING TO SHOW?

Derive the exact mathematical expectation \(\mathbb{E}[e'e \mid X] = \sigma^2(n - k)\) using the residual-maker matrix \(M\), demonstrating why dividing by \(n - k\) yields an unbiased estimator \(s^2\) of \(\sigma^2\).

1

Express Residuals via the Residual-Maker Matrix \(M\)

Recall the symmetric, idempotent projection matrix \(M = I_n - X(X'X)^{-1}X'\) from Module 2:

$$e = My = M(X\beta + \varepsilon) = MX\beta + M\varepsilon = M\varepsilon$$
WHY THIS STEP? Because \(MX = \mathbf{0}\), the systematic parameter vector \(\beta\) drops out, isolating the pure disturbance vector \(\varepsilon\).
2

Form the Quadratic Expression for \(e'e\)

Using symmetry (\(M' = M\)) and idempotence (\(M^2 = M\)):

$$e'e = (M\varepsilon)'(M\varepsilon) = \varepsilon' M' M \varepsilon = \varepsilon' M \varepsilon$$
WHY THIS STEP? Reduces the sum of squared residuals to a scalar quadratic form in the random disturbance vector \(\varepsilon\).
3

Apply the Trace Expectation Lemma

Since \(\varepsilon' M \varepsilon\) is a \(1 \times 1\) scalar, it equals its trace. Using the cyclic property of trace \(\operatorname{tr}(AB) = \operatorname{tr}(BA)\):

$$\mathbb{E}[e'e \mid X] = \mathbb{E}[\operatorname{tr}(\varepsilon' M \varepsilon) \mid X] = \mathbb{E}[\operatorname{tr}(M \varepsilon \varepsilon') \mid X] = \operatorname{tr}(M \mathbb{E}[\varepsilon\varepsilon' \mid X])$$
WHY THIS STEP? Moving expectation inside the trace operator allows us to substitute \(\mathbb{E}[\varepsilon\varepsilon' \mid X] = \sigma^2 I_n\).
4

Calculate \(\operatorname{tr}(M)\)

Evaluate the trace of the residual-maker matrix:

$$\operatorname{tr}(M) = \operatorname{tr}(I_n) - \operatorname{tr}\left(X(X'X)^{-1}X'\right) = n - \operatorname{tr}\left((X'X)^{-1}X'X\right) = n - \operatorname{tr}(I_k) = n - k$$
WHY THIS STEP? The cyclic trace property \(\operatorname{tr}(AB) = \operatorname{tr}(BA)\) reveals that projecting onto \(k\) regressors consumes exactly \(k\) degrees of freedom.
5

Obtain the Unbiased Estimator \(s^2\)

Combining steps 3 and 4 yields the exact expectation:

$$\mathbb{E}[e'e \mid X] = \sigma^2 \operatorname{tr}(M) = \sigma^2 (n - k)$$

Dividing both sides by \(n - k\) demonstrates that \(s^2 = \frac{e'e}{n - k}\) is strictly unbiased:

$$\mathbb{E}[s^2 \mid X] = \mathbb{E}\left[\frac{e'e}{n - k} \;\middle|\; X\right] = \frac{\sigma^2(n - k)}{n - k} = \sigma^2$$
WHY THIS STEP? Dividing by \(n - k\) cancels the shrinkage factor \(\frac{n - k}{n}\), yielding an unbiased estimator of \(\sigma^2\).
⚖️ DEGREES OF FREEDOM INTUITION: WHY DIVIDE BY \(n - k\)?

Think of degrees of freedom as independent pieces of outcome information:

n observations of y − k estimated coefficients = n − k residual degrees of freedom

Academic Caution: This is an intuitive geometric summary: the OLS normal equations \(X'e = \mathbf{0}\) impose \(k\) exact linear restrictions on the \(n\) residuals, forcing \(e\) to lie in an \((n - k)\)-dimensional subspace. Residuals are not literally mutually independent random variables, but their sum of squares behaves in expectation as \((n - k)\) independent variance units.

KEY EQUATION Unbiased Error Variance Estimator (s²)
$$s^2 = \frac{e'e}{n - k} \implies \widehat{\operatorname{Var}}(\hat{\beta} \mid X) = s^2(X'X)^{-1}$$
WHERE
\(s^2\)
Regression Mean Squared Error: Feasible sample estimator of disturbance variance \(\sigma^2\). Unbiased: \(\mathbb{E}[s^2 \mid X] = \sigma^2\).
\(e'e = \sum_{i=1}^n e_i^2\)
Sum of Squared Residuals: Total squared residual length minimized by OLS.
\(n - k\)
Residual Degrees of Freedom: \(n\) observations minus \(k\) constraints imposed by the normal equations \(X'e = \mathbf{0}\).
\(\widehat{\operatorname{Var}}(\hat{\beta} \mid X)\)
Estimated Variance Matrix: Population \(\sigma^2\) replaced by feasible sample estimator \(s^2\).

Can You Explain It? The Meaning of "Best"

A researcher argues: "The Gauss–Markov theorem proves that OLS is the best possible estimator of \(\beta\) under all circumstances, so there is never any justification for using Ridge regression, Lasso, or nonlinear estimation." How would you critique this statement based on what we actually proved?

Show Conceptual Explanation
Answer: The researcher's claim overstates the scope of Gauss–Markov in two critical ways:
  1. Class Restriction: Gauss–Markov only proves optimality within the restricted class of linear unbiased estimators. It says nothing about nonlinear estimators (e.g., Maximum Likelihood in non-normal settings or neural networks).
  2. The Bias-Variance Tradeoff: Shrinkage estimators like Ridge or Lasso intentionally introduce a small amount of bias in exchange for a massive reduction in variance when regressors are collinear. As a result, Ridge regression can easily achieve a lower Mean Squared Error (\(\text{MSE} = \text{Bias}^2 + \text{Variance}\)) than OLS.

✅ Quick Check: Degrees of Freedom in \(s^2\)

An empirical model with \(n = 25\) observations and \(k = 5\) estimated parameters produces \(\sum e_i^2 = 80\). What is the naive variance estimate \(\frac{1}{n}e'e\), and what is the unbiased estimate \(s^2\)?

Show Answer & Calculation
Naive estimate: \(\frac{80}{25} = 3.20\).
Unbiased estimate: \(s^2 = \frac{e'e}{n - k} = \frac{80}{25 - 5} = \frac{80}{20} = 4.00\).

WHY? Because OLS minimizes \(\sum e_i^2\), sample residuals mechanically hug the sample data tighter than true errors \(\varepsilon\). The naive estimate underestimates \(\sigma^2\) by 20% because it ignores the 5 parameter constraints.
📖 WHAT YOU SHOULD NOW UNDERSTAND (LESSON 3.6 REVISION)
  • Gauss–Markov Definition: OLS is the Best Linear Unbiased Estimator (BLUE) under spherical homoskedastic errors \(\operatorname{Var}(\varepsilon \mid X) = \sigma^2 I_n\).
  • Variance Decomposition: Any alternative linear unbiased estimator \(\tilde{\beta} = Cy\) has variance \(\operatorname{Var}(\tilde{\beta} \mid X) = \operatorname{Var}(\hat{\beta} \mid X) + \sigma^2 DD'\). Because \(DD' \ge \mathbf{0}\), OLS variance is minimal.
  • Scope of BLUE: Gauss–Markov does not say OLS is superior to all possible estimators; biased shrinkage estimators (like Ridge) or nonlinear estimators may achieve lower Mean Squared Error.
  • Residual Variance Expectation: \(\mathbb{E}[e'e \mid X] = \sigma^2(n - k)\). The naive estimator \(\frac{1}{n}e'e\) is downward biased by a factor of \(\frac{n - k}{n}\).
  • Unbiased Variance Estimator: Dividing by residual degrees of freedom \(n - k\) yields \(s^2 = \frac{e'e}{n - k}\), leading to the estimated covariance matrix \(\widehat{\operatorname{Var}}(\hat{\beta} \mid X) = s^2(X'X)^{-1}\).
