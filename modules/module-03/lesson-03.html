LESSON 3.3 Joint Hypothesis Testing

R-Squared & F Tests

Learn how econometricians test linear restrictions on regression models by measuring the drop in explanatory power between unrestricted and restricted specifications using the \(F\)-statistic.

🎯 Learning Objectives

  • Formulate the unrestricted and restricted regression specifications for linear hypothesis testing.
  • Derive and interpret the \(R^2\)-based \(F\)-statistic formula: \(F[J, n - k] = \frac{(R^2 - R_r^2) / J}{(1 - R^2) / (n - k)}\).
  • Identify numerator degrees of freedom (\(J\) restrictions) and denominator degrees of freedom (\(n - k\)).
  • Explain the intuition: comparing normalized fit lost to remaining normalized residual variance.
  • Demonstrate that testing all slopes simultaneously yields a restricted \(R_r^2 = 0\).

1. The Unrestricted and Restricted Framework

The \(F\)-test provides a formal statistical framework for testing joint linear restrictions: we compare the fit of an unconstrained model to a simpler model where hypothesized constraints are imposed.

The Hypothesis Testing Story: Did Fit Deteriorate Substantially?

Start with the full model containing all candidate regressors. Next, impose \(J\) linear restrictions (such as setting coefficients to zero). Did the explanatory power plunge, or did it drop by only a negligible amount consistent with sampling chance?

2. The F-Statistic via R-Squared: Tall Fraction Architecture

The \(F\)-statistic normalizes the loss of explanatory power per restriction by the remaining unexplained residual variation per residual degree of freedom.

KEY EQUATION Degrees of Freedom: \(F \sim F[J, n - k]\) under \(H_0\)
$$F = \frac{\dfrac{R^2 - R_r^2}{J}}{\dfrac{1 - R^2}{n - k}}$$
Numerator: Signal (Fit Lost)

Average loss of fit per restriction: \(\frac{R^2 - R_r^2}{J}\) measures how much explanatory power was sacrificed per parameter constraint imposed on the model.

Denominator: Noise (Residual Variance)

Residual variation per residual degree of freedom: \(\frac{1 - R^2}{n - k}\) scales the signal by the baseline noise remaining in the unrestricted specification.

Sum of Squares Equivalence: Because total sum of squares \(\text{SST}\) cancels from both the numerator and denominator, the \(R^2\)-based \(F\) is mathematically identical to the sum-of-squared-residuals formulation: \(F = \frac{(\text{SSE}_r - \text{SSE}_u) / J}{\text{SSE}_u / (n - k)}\)

🔎 What to Notice
If \(R_r^2\) is close to \(R^2\), the amber segment is tiny, driving the \(F\)-statistic toward zero (cannot reject \(H_0\)). As the gap \((R^2 - R_r^2)\) widens, \(F\) surges upward.
◆ Why It Matters
Individual \(t\)-tests can be misleading when regressors are collinear: each separate \(t\)-test may fail to reject zero, yet the joint \(F\)-test emphatically rejects the hypothesis that all coefficients are zero.
📊 Econometric Interpretation
The \(F\)-statistic is an omnibus test of linear restrictions. It answers whether the variables in question collectively provide explanatory power that exceeds what chance sampling error could produce.

4. Special Case: Overall Model Significance (\(R_r^2 = 0\))

A frequent application is testing whether all slope coefficients in the regression are jointly zero:

\(H_0: \beta_1 = \beta_2 = \dots = \beta_{k-1} = 0\)

Under this null hypothesis, the restricted model contains only the constant intercept: \(y_i = \beta_0 + \varepsilon_i\). The OLS estimator of a model with only an intercept is simply the sample mean: \(\hat{\beta}_0 = \bar{y}\).

📌 Source Result: R²_r = 0

When all slope coefficients are zero, the fitted values equal the sample mean: \(\hat{y}_i = \bar{y}\). Thus the restricted regression sum of squares is zero: \[ \text{SSR}_r = \sum_{i=1}^n (\bar{y} - \bar{y})^2 = 0 \implies R_r^2 = \frac{\text{SSR}_r}{\text{SST}} = 0 \] The overall model \(F\)-statistic simplifies directly to: \[ F[k - 1, n - k] = \frac{R^2 / (k - 1)}{(1 - R^2) / (n - k)} \] This is the standard overall \(F\)-statistic reported at the bottom of every econometric regression output table.

🧠

Can You Explain It? Conceptual Check

Question: Why can an \(F\)-test reject the joint null hypothesis \(H_0: \beta_1 = \beta_2 = 0\) even when both individual \(t\)-tests fail to reject \(\beta_1 = 0\) and \(\beta_2 = 0\)?

Show Explanation
Explanation: High multicollinearity between \(x_1\) and \(x_2\) inflates their individual coefficient standard errors, driving individual \(t\)-statistics toward zero. However, omitting both regressors simultaneously creates a large loss of fit \((R^2 - R_r^2)\). The \(F\)-test accounts for the joint covariance structure and detects that the regressors collectively explain significant outcome variation.

✅ Quick Check: Calculating F from R²

An unrestricted model with \(n = 64\) and \(k = 4\) parameters yields \(R^2 = 0.50\). Imposing \(J = 2\) exclusions drops the fit to \(R_r^2 = 0.40\). What is the \(F\)-statistic?

Show Answer & Calculation
ANSWER: \(F = 6.00\).

WHY?
Numerator: \((R^2 - R_r^2) / J = (0.50 - 0.40) / 2 = 0.10 / 2 = 0.05\).
Denominator: \((1 - R^2) / (n - k) = (1 - 0.50) / (64 - 4) = 0.50 / 60 = 0.008333\).
\(F = \frac{0.05}{0.008333} = 6.00\). With \(F[2, 60]\), this exceeds standard critical values (~3.15), rejecting \(H_0\).
📋

What You Should Now Understand

  • The \(F\)-test evaluates whether imposing \(J\) linear restrictions causes a statistically significant drop in explanatory power (\(R^2 - R_r^2\)).
  • The \(F\)-statistic formula \(F = \frac{(R^2 - R_r^2)/J}{(1 - R^2)/(n - k)}\) balances the average loss of fit per restriction against the unexplained residual variance per degree of freedom.
  • Testing all slope parameters simultaneously yields a restricted fit of \(R_r^2 = 0\) because a model with only an intercept predicts \(\bar{y}\) for all observations.
  • Joint \(F\)-testing overcomes multicollinearity where individual \(t\)-tests fail to reject coefficients separately.
