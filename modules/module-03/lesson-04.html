LESSON 3.4 Finite-Sample Properties

OLS Unbiasedness & Omitted Variable Bias

Move from in-sample goodness of fit to the finite-sample sampling distribution of the OLS estimator. Derive conditional unbiasedness under strict exogeneity and master the exact mathematics and diagnostic table of omitted-variable bias.

🎯 Learning Objectives

  • State the finite-sample conditional unbiasedness property: \(\mathbb{E}[b \mid X] = \beta\).
  • Derive unbiasedness from the structural decomposition \(b = \beta + (X'X)^{-1}X'\varepsilon\).
  • Identify CLRM Assumption 3 (\(\mathbb{E}[X'\varepsilon \mid X] = \mathbf{0}\)) as the crucial exogeneity condition.
  • Derive the omitted variable bias (OVB) expression: \(\mathbb{E}[b_1 \mid X] = \beta_1 + (X_1'X_1)^{-1}X_1'X_2\beta_2\).
  • Evaluate the source's 2×2 bias table and state the two precise conditions that eliminate bias.

1. Finite-Sample Property 1: Unbiasedness

Conditional unbiasedness guarantees that across hypothetical repeated random samples conditioning on regressor matrix \(X\), the OLS estimator produces estimates that center squarely on the true population parameter \(\beta\).

The Core Decomposition: True Parameter + Random Estimation Error

Before doing algebra, observe how the OLS estimator separates into an unvarying truth plus a sample-dependent error term:

OLS Estimate
\(\hat{\beta}\)
Realized estimate from sample
=
True Parameter
\(\beta\)
Fixed population parameter vector
+
Estimation Error
\((X'X)^{-1}X'\varepsilon\)
Random error from disturbance \(\varepsilon\)
The Unbiasedness Mechanism: If \(\mathbb{E}[\varepsilon \mid X] = \mathbf{0}\), the expected estimation error vanishes completely: \(\mathbb{E}[(X'X)^{-1}X'\varepsilon \mid X] = (X'X)^{-1}X'\mathbb{E}[\varepsilon \mid X] = \mathbf{0}\). Therefore, \(\mathbb{E}[\hat{\beta} \mid X] = \beta\).
Finite-Sample Derivation

Conditional Unbiasedness of the OLS Estimator

What are we trying to show?

Prove that under the strict exogeneity assumption \(\mathbb{E}[\varepsilon \mid X] = \mathbf{0}\), the expected value of \(\hat{\beta}\) conditional on \(X\) equals the true population coefficient vector \(\beta\).

1

Write the OLS estimator closed-form solution

Express the OLS coefficient vector \(\hat{\beta}\) in terms of data matrices \(X\) and \(y\):

\(\hat{\beta} = (X'X)^{-1}X'y\)
Why this step works This is the unique minimizer of the sum of squared residuals derived from the normal equations in Module 2.
2

Substitute the true data-generating process

Insert the population equation \(y = X\beta + \varepsilon\) into the OLS formula:

\(\hat{\beta} = (X'X)^{-1}X'(X\beta + \varepsilon)\)
Why this step works We evaluate how the sample estimator behaves when outcomes are genuinely generated by parameter vector \(\beta\) and random disturbances \(\varepsilon\).
3

Separate the true parameter from estimation error

Distribute \((X'X)^{-1}X'\) across the sum and simplify \((X'X)^{-1}X'X = I_k\):

\(\hat{\beta} = (X'X)^{-1}X'X\beta + (X'X)^{-1}X'\varepsilon = \beta + (X'X)^{-1}X'\varepsilon\)
Why this step works Matrix inversion simplifies the first term to identity \(I_k\), cleanly isolating the population truth \(\beta\) from the sample noise component.
4

Condition on the regressor matrix X

Take the conditional expectation of both sides holding \(X\) fixed:

\(\mathbb{E}[\hat{\beta} \mid X] = \beta + \mathbb{E}[(X'X)^{-1}X'\varepsilon \mid X] = \beta + (X'X)^{-1}X'\mathbb{E}[\varepsilon \mid X]\)
Why this step works Because we condition on \(X\), the matrix function \((X'X)^{-1}X'\) behaves as a non-random constant and factors outside the expectation operator.
5

Apply the exogeneity assumption

CLRM Assumption 3

Apply strict exogeneity \(\mathbb{E}[\varepsilon \mid X] = \mathbf{0}\) (or \(\mathbb{E}[X'\varepsilon \mid X] = \mathbf{0}\)):

\(\mathbb{E}[\hat{\beta} \mid X] = \beta + (X'X)^{-1}X'\mathbf{0} = \beta + \mathbf{0} = \beta\)
Why this step works Under exogeneity, unobserved factors are on average uncorrelated with regressors; hence the expected sampling estimation error is zero.
💡

Big Picture: What Does Unbiasedness Really Mean?

Unbiasedness does not guarantee that any single sample estimate \(\hat{\beta}\) will exactly equal \(\beta\). Rather, it guarantees that the OLS estimation rule does not systematically overshoot or undershoot: the average of estimates across thousands of hypothetical random samples drawn from the same population centers precisely on \(\beta\).

2. Omitted Variable Bias (OVB)

Omitted variable bias occurs when an investigator omits an important explanatory factor from the empirical regression.

Intuition First: Omitted-Variable Bias Requires TWO Ingredients

An omitted variable \(X_2\) causes bias in the included coefficient \(\hat{\beta}_1\) if and only if both ingredients occur simultaneously:

Ingredient 1
The omitted variable affects y (\(\beta_2 \neq 0\))
The omitted factor must be a true structural determinant of the outcome.
Ingredient 2
The omitted variable is related to \(X_1\) (\(X_1'X_2 \neq 0\))
The omitted factor must not be orthogonal to the included regressors.
Matrix Derivation

Omitted Variable Bias Formula

What are we trying to show?

Quantify the estimation bias in \(\hat{\beta}_1\) when regressing \(y\) only on \(X_1\) while the true data-generating process contains both \(X_1\) and \(X_2\).

1

Specify the true model and estimated short regression

Define the true relationship and the researcher's estimated model:

\(\text{True Model: } y = X_1\beta_1 + X_2\beta_2 + \varepsilon \quad \implies \quad \text{Short OLS: } \hat{\beta}_1 = (X_1'X_1)^{-1}X_1'y\)
Why this step works The researcher omits \(X_2\) and calculates standard OLS using only the included regressor matrix \(X_1\).
2

Substitute the full data-generating equation into \(\hat{\beta}_1\)

Insert the true \(y\) into the short regression estimator:

\(\hat{\beta}_1 = (X_1'X_1)^{-1}X_1'(X_1\beta_1 + X_2\beta_2 + \varepsilon)\)
Why this step works The realized data \(y\) genuinely contains responses to both \(X_1\) and \(X_2\), even though the researcher only conditions on \(X_1\).
3

Distribute and evaluate conditional expectation

Fundamental OVB Identity

Expand terms and take conditional expectation assuming \(\mathbb{E}[\varepsilon \mid X_1, X_2] = \mathbf{0}\):

\(\mathbb{E}[\hat{\beta}_1 \mid X] = \beta_1 + (X_1'X_1)^{-1}X_1'X_2\beta_2 + (X_1'X_1)^{-1}X_1'\mathbb{E}[\varepsilon \mid X] = \beta_1 + (X_1'X_1)^{-1}X_1'X_2\beta_2\)
Why this step works \((X_1'X_1)^{-1}X_1'X_1\beta_1 = \beta_1\). The disturbance term vanishes under exogeneity, leaving the omitted variable bias term \((X_1'X_1)^{-1}X_1'X_2\beta_2\).
💡

Big Picture: Anatomy of the Bias Expression

The bias \(\mathbb{E}[\hat{\beta}_1 \mid X] - \beta_1 = (X_1'X_1)^{-1}X_1'X_2\beta_2\) equals the auxiliary regression coefficients of the omitted variable on the included regressors (\(\tilde{\delta}_{21} = (X_1'X_1)^{-1}X_1'X_2\)) multiplied by the structural effect of the omitted variable on the outcome (\(\beta_2\)).

3. The Classic 2×2 Bias Diagnostic Table

The source document (Econometrics (3).pdf, page 3) organizes the two-ingredient condition into a fundamental diagnostic table:

Relationship to Included Regressors \(\beta_2 = 0\) (Omitted \(X_2\) does not affect \(y\)) \(\beta_2 \neq 0\) (Omitted \(X_2\) affects \(y\))
\(X_1'X_2 = \mathbf{0}\)
Orthogonal in sample 		✓ UNBIASED
No bias: \(\beta_2 = 0\) and \(X_1'X_2 = 0\) 		✓ UNBIASED
No bias: \(X_1'X_2 = 0\) eliminates transmission
\(X_1'X_2 \neq \mathbf{0}\)
Correlated with \(X_1\) 		✓ UNBIASED
No bias: \(\beta_2 = 0\) (omitted factor is irrelevant) 		✗ BIASED
\(\text{Bias} = (X_1'X_1)^{-1}X_1'X_2\beta_2 \neq \mathbf{0}\)
📌 Academic Precision Note

In the source matrix expression, \(X_1'X_2 \neq 0\) represents sample non-orthogonality between included and excluded regressor columns. This bias expression demonstrates how the influence of omitted \(X_2\) leaks into the coefficient on \(X_1\) whenever \(X_2\) genuinely affects \(y\) and is non-orthogonal to \(X_1\).

👁 What You Are Seeing
A directed causal path model: \(X_1\) affects \(Y\) directly with true coefficient \(\beta_1 = 2.0\). The omitted factor \(X_2\) connects to \(X_1\) through correlation \(\delta_{21}\) and to \(Y\) through \(\beta_2\).
🔎 What to Notice
Bias only arises when both connections are active (the lower right quadrant of the bias table). If either the link from \(X_1\) to \(X_2\) is severed (\(\delta_{21} = 0\)) or the link to \(Y\) is zero (\(\beta_2 = 0\)), the bias vanishes completely.
◆ Why It Matters
This explains why randomized controlled trials (RCTs) work: random treatment assignment forces \(X_1'X_2 = \mathbf{0}\) for all baseline covariates, guaranteeing unbiased treatment effect estimates even when confounders remain unmeasured.
📊 Econometric Interpretation
In an observational wage equation omitting ability (\(X_2\)), schooling (\(X_1\)) is positively correlated with ability (\(\delta_{21} > 0\)) and ability raises wages (\(\beta_2 > 0\)). Hence OLS on schooling overstates the true causal return to education.
💡 Try This: Uncheck Correlated with X₁ while keeping \(\beta_2 = 1.5\). Notice that the auxiliary slope collapses to zero and \(\mathbb{E}[\hat{\beta}_1 \mid X]\) snaps back to the unbiased value of 2.00!
⚠️ Common Mistake

"Any omitted variable automatically causes bias in an OLS regression."
Correction: Millions of variables are omitted from every empirical regression. An omitted factor only produces bias if it simultaneously satisfies two conditions: (1) it affects \(y\) (\(\beta_2 \neq 0\)), and (2) it is non-orthogonal to the included regressors (\(X_1'X_2 \neq 0\)). Omitted noise or orthogonal factors do not cause bias.

🧠

Can You Explain It? Conceptual Check

Question: What exact two conditions must occur simultaneously for an omitted variable to bias an included coefficient?

Show Explanation
Two Conditions:
1. Impact on Outcome: The omitted variable must be a true determinant of \(y\) in the population model (\(\beta_2 \neq 0\)).
2. Correlation with Regressor: The omitted variable must be correlated / non-orthogonal to the included explanatory variable (\(X_1'X_2 \neq 0\)).
If either condition fails, the bias term \((X_1'X_1)^{-1}X_1'X_2\beta_2 = \mathbf{0}\) and the included coefficient remains unbiased.

✅ Quick Check: Direction of Bias

In a health outcome regression, cigarette smoking (\(X_1\)) is negatively correlated with physical exercise (\(X_2\), \(\delta_{21} < 0\)). Exercise has a positive true effect on health (\(\beta_2 > 0\)). If exercise is omitted, what is the direction of the bias on smoking?

Show Answer & Derivation
ANSWER: Negative bias (downward).

WHY? \(\text{Bias} = \delta_{21} \cdot \beta_2 = (\text{negative}) \times (\text{positive}) = \text{negative}\). The OLS coefficient on smoking will be biased downward (appearing more harmful than its true direct pharmacological effect), because it picks up the omitted health detriment of sedentary behavior among smokers.
📋

What You Should Now Understand

  • OLS is conditionally unbiased (\(\mathbb{E}[\hat{\beta} \mid X] = \beta\)) under the exogeneity assumption \(\mathbb{E}[\varepsilon \mid X] = \mathbf{0}\) because the estimation error \((X'X)^{-1}X'\varepsilon\) has mean zero.
  • Unbiasedness is a property of the estimator across repeated random sampling, not a guarantee for any single sample realization.
  • Omitted variable bias occurs if and only if the omitted variable is both a true determinant of the outcome (\(\beta_2 \neq 0\)) and non-orthogonal to the included regressors (\(X_1'X_2 \neq 0\)).
  • The OVB formula \(\text{Bias} = (X_1'X_1)^{-1}X_1'X_2\beta_2\) reveals that random assignment in experiments eliminates bias by ensuring \(X_1'X_2 = \mathbf{0}\).
