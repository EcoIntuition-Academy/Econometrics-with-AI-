LESSON 18.4 Model Assessment & Inference

Prediction, Model Fit & Wald Testing in MNL

Compute predicted choice probabilities, evaluate convergence log-likelihood and McFadden's pseudo-R², assess classification accuracy under outcome imbalance, and conduct single and joint Wald hypothesis tests on covariate vectors.

🎯 Learning Objectives

  • Calculate individual predicted choice probabilities using both the general and normalized Multinomial Logit forms.
  • Evaluate goodness-of-fit using convergence log-likelihood and McFadden's pseudo-\(R^2 = 1 - \frac{\ln L_{\text{model}}}{\ln L_{\text{null}}}\).
  • Understand why overall prediction accuracy (\(\frac{\text{Number of correct predictions}}{n}\)) can be deceptive in discrete choice datasets with imbalanced outcome distributions.
  • Conduct single-coefficient Wald tests (\(W \sim \chi^2(1)\)) and joint Wald tests (\(W \sim \chi^2(J)\)) across alternatives, reproducing the lecture education test (\(W = 14.81 \sim \chi^2(2)\)).

1. Predicted Probabilities in MNL

Once the parameter vectors \(\hat{\boldsymbol{\beta}}_1, \dots, \hat{\boldsymbol{\beta}}_J\) have been estimated, we calculate the predicted choice probability \(\hat{P}_{ij}\) that individual \(i\) with observed characteristics \(\mathbf{x}_i\) selects alternative \(j\).

Reflecting the location normalization \(\hat{\boldsymbol{\beta}}_0 = \mathbf{0}\) established in Lesson 18.1, the predicted probabilities take the normalized representation:

PREDICTION Predicted Choice Probabilities
\[ \hat{P}_{ij} = \frac{\exp(\mathbf{x}_i'\hat{\boldsymbol{\beta}}_j)}{1 + \sum_{k=1}^J \exp(\mathbf{x}_i'\hat{\boldsymbol{\beta}}_k)}, \quad \text{for } j = 1, \dots, J \] \[ \hat{P}_{i0} = \frac{1}{1 + \sum_{k=1}^J \exp(\mathbf{x}_i'\hat{\boldsymbol{\beta}}_k)}, \quad \text{for Base Category } j = 0 \]
FORMULATION NOTE:
General Form Equivalently written as \(\hat{P}_{ij} = \frac{\exp(\mathbf{x}_i'\hat{\boldsymbol{\beta}}_j)}{\sum_{k=0}^J \exp(\mathbf{x}_i'\hat{\boldsymbol{\beta}}_k)}\) with \(\hat{\boldsymbol{\beta}}_0 = \mathbf{0}\) (where \(\exp(\mathbf{x}_i'\hat{\boldsymbol{\beta}}_0) = \exp(0) = 1\)).
Individual Profiling Enables out-of-sample choice forecasting: given any vector of demographics \(\mathbf{x}_*\), the model outputs a coherent probability distribution over all alternatives.

2. Model Fit: Log-Likelihood & McFadden's Pseudo-\(R^2\)

The primary metric of overall sample fit is the log-likelihood at convergence:

\[ \ln L = \sum_{i=1}^n \sum_{j=0}^J d_{ij} \ln(\hat{P}_{ij}) \]

Because probabilities satisfy \(0 < \hat{P}_{ij} \le 1\), their logarithms are negative (\(\ln \hat{P}_{ij} \le 0\)), making \(\ln L \le 0\). Higher (less negative) values indicate that the model assigns higher probabilities to the actual choices observed in the sample.

GOODNESS-OF-FIT McFadden's Pseudo-\(R^2\)
\[ R^2_{\text{McFadden}} = 1 - \frac{\ln L_{\text{model}}}{\ln L_{\text{null}}} \]
COMPONENTS & BENCHMARKS:
\(\ln L_{\text{model}}\) Maximized log-likelihood from the full model including all explanatory covariates \(\mathbf{x}_i\).
\(\ln L_{\text{null}}\) Log-likelihood from the intercept-only (null) model with no covariates, predicting choices purely from sample shares.
Lecture Rule of Thumb As explicitly stated in the course notes: values between 0.20 and 0.40 are considered a decent fit for discrete choice models.

3. Prediction Accuracy & The Imbalance Warning

In applied work, researchers frequently compute a classification matrix (confusion matrix) by predicting the choice with the highest modeled probability:

\[ \hat{y}_i = \arg\max_{j \in \{0, 1, \dots, J\}} \hat{P}_{ij} \] \[ \text{Prediction Accuracy} = \frac{\sum_{i=1}^n \mathbf{1}(\hat{y}_i = y_i)}{n} \]

⚠ CRITICAL LECTURE WARNING · ACCURACY CAN MISLEAD IN IMBALANCED DATA

As stressed on Page 7 of the lecture source: prediction accuracy can be highly misleading when choice outcomes are imbalanced. For example, if \(85\%\) of commuters drive a car, a naive null model that predicts "Car" for every single person achieves an impressive \(85\%\) accuracy rate while offering zero explanatory power for bus or train commuters! Always evaluate predictive capability alongside \(\ln L\) and pseudo-\(R^2\).

4. Hypothesis Testing: Single & Joint Wald Tests

We evaluate the statistical significance of individual parameters or groups of coefficients using Wald test statistics.

Single-Coefficient Wald Test

To test whether a single covariate \(x_r\) has a statistically significant effect on alternative \(j\) relative to the base category (\(H_0: \beta_{jr} = 0\)):

TEST STATISTIC Single-Coefficient Wald Statistic
\[ W = \frac{\hat{\beta}_{jr}^2}{\widehat{\text{Var}}(\hat{\beta}_{jr})} = \left(\frac{\hat{\beta}_{jr}}{\text{SE}(\hat{\beta}_{jr})}\right)^2 \sim \chi^2(1) \]

Joint Wald Test Across All Alternatives

Often the primary economic question is whether a covariate \(x_r\) (e.g., education or age) has any effect whatsoever across the choice set. This corresponds to the joint null hypothesis that all \(J\) non-base coefficients for regressor \(r\) are simultaneously zero:

\[ H_0: \beta_{1r} = \beta_{2r} = \dots = \beta_{Jr} = 0 \]
JOINT TEST Joint Wald Test Across Alternatives
\[ W = \hat{\boldsymbol{\beta}}_r' \left[ \widehat{\text{Var}}(\hat{\boldsymbol{\beta}}_r) \right]^{-1} \hat{\boldsymbol{\beta}}_r \sim \chi^2(J) \]
DIMENSIONS & STRUCTURE:
\(\hat{\boldsymbol{\beta}}_r\) \(J \times 1\) vector stacking the estimated coefficients for regressor \(r\): \((\hat{\beta}_{1r}, \dots, \hat{\beta}_{Jr})'\).
\(\widehat{\text{Var}}(\hat{\boldsymbol{\beta}}_r)\) \(J \times J\) estimated asymptotic covariance submatrix for the vector \(\hat{\boldsymbol{\beta}}_r\).
Degrees of Freedom Under \(H_0\), the statistic follows an asymptotic \(\chi^2\) distribution with \(J\) degrees of freedom.

AUTHORITATIVE SOURCE EXAMPLE · JOINT SIGNIFICANCE OF EDUCATION (PAGE 8)

Suppose you estimate an MNL model with 3 alternatives (Base = Option 0, Option 1, Option 2). The variable "education" has estimated coefficients and standard errors:

\(\hat{\beta}_{1, \text{educ}} = 0.70, \quad \text{SE} = 0.20\)
\(\hat{\beta}_{2, \text{educ}} = 0.40, \quad \text{SE} = 0.25\)

The joint Wald test statistic for \(H_0: \beta_{1, \text{educ}} = \beta_{2, \text{educ}} = 0\) is computed as the sum of squared standardized coefficients:

\[ W = \frac{0.70^2}{0.20^2} + \frac{0.40^2}{0.25^2} = \frac{0.49}{0.04} + \frac{0.16}{0.0625} = 12.25 + 2.56 = \mathbf{14.81} \sim \chi^2(2) \]

Conclusion: The critical value for \(\chi^2(2)\) at the \(1\%\) significance level is \(9.21\). Because \(W = 14.81 > 9.21\) (\(p = 0.0006\)), we decisively reject \(H_0\) at the 1% level. There is overwhelming evidence that education significantly affects choice among the three alternatives.

6. Quick Knowledge Check

Question: Degrees of Freedom in Joint Hypothesis Testing

An econometrician estimates a Multinomial Logit model with \(5\) total alternatives (Options \(0, 1, 2, 3, 4\)) where Option 0 is normalized to \(\boldsymbol{\beta}_0 = \mathbf{0}\). To test whether the regressor "household income" has any joint effect across the model, what are the degrees of freedom of the joint Wald test statistic?

Hint: How many non-base alternatives are estimated? How many restriction equations are imposed under \(H_0: \beta_{1, \text{inc}} = \dots = \beta_{J, \text{inc}} = 0\)?

Solution:
With 5 total alternatives, there are \(J = 4\) non-base alternatives (\(j = 1, 2, 3, 4\)) with freely estimated parameters. The null hypothesis tests: \[ H_0: \beta_{1, \text{inc}} = \beta_{2, \text{inc}} = \beta_{3, \text{inc}} = \beta_{4, \text{inc}} = 0 \] This imposes exactly \(q = J = 4\) parameter restrictions. The joint Wald statistic follows an asymptotic \(\chi^2(4)\) distribution.

Lesson 18.4 Summary

In this lesson, we analyzed model evaluation and hypothesis testing in multinomial logit:

  • Predicted Probabilities: Derived from estimated parameters using the normalized representation with \(\hat{\boldsymbol{\beta}}_0 = \mathbf{0}\).
  • McFadden's Pseudo-\(R^2\): Measures relative improvement over the null model (\(1 - \ln L_M / \ln L_0\)); values of 0.20–0.40 indicate decent fit.
  • Imbalance Warning: Raw accuracy can hide model failure on minority choice categories.
  • Joint Wald Tests: Test covariate relevance across all alternatives via \(W = \hat{\boldsymbol{\beta}}_r' [\widehat{\text{Var}}(\hat{\boldsymbol{\beta}}_r)]^{-1}\hat{\boldsymbol{\beta}}_r \sim \chi^2(J)\).
