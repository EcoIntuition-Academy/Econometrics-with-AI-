LESSON 17.5 Overidentification & Weighting

GMM with Instruments: IV & Weighting

Extend the method of moments when regressors are endogenous: define instrument matrices with \(L > K\), contrast just-identified IV with overidentified GMM, formulate the quadratic objective function, and analyze weighting matrix choices.

🎯 Learning Objectives

  • Formulate instrument-residual moment conditions \(\mathbb{E}[\mathbf{z}_i (y_i - \mathbf{x}_i'\boldsymbol{\beta})] = \mathbf{0}\) when \(\mathbf{Z} \ne \mathbf{X}\).
  • Distinguish the three identification regimes: underidentified (\(L < K\)), just-identified (\(L = K\)), and overidentified (\(L > K\)).
  • Prove that when \(L = K\), GMM reduces to the classical Instrumental Variables (IV) estimator.
  • Construct the quadratic GMM objective function \(Q_n(\boldsymbol{\beta}) = \hat{\mathbf{g}}(\boldsymbol{\beta})' \mathbf{W} \hat{\mathbf{g}}(\boldsymbol{\beta})\).
  • Show that choosing the weighting matrix \(\mathbf{W} = (\mathbf{Z}'\mathbf{Z})^{-1}\) derives the Two-Stage Least Squares (2SLS) estimator.

1. Instrumental Variables and Moment Conditions

When regressors are endogenous (i.e., \(\mathbb{E}[\mathbf{x}_i \varepsilon_i] \ne \mathbf{0}\)), Ordinary Least Squares fails to be consistent. We introduce an instrument matrix \(\mathbf{Z}\) containing variables that are correlated with \(\mathbf{X}\) but orthogonal to \(\boldsymbol{\varepsilon}\).

Let \(\mathbf{Z}\) be an \(n \times L\) matrix of instruments and \(\mathbf{X}\) be an \(n \times K\) matrix of regressors:

MOMENT SPECIFICATION · ORTHOGONALITY

Population and Sample Moment Conditions with Instruments

\[ \mathbb{E}[\mathbf{z}_i \varepsilon_i] = \mathbb{E}\left[ \mathbf{z}_i (y_i - \mathbf{x}_i'\boldsymbol{\beta}) \right] = \mathbf{0} \] \[ \hat{\mathbf{g}}(\boldsymbol{\beta}) = \frac{1}{n} \sum_{i=1}^n \mathbf{z}_i (y_i - \mathbf{x}_i'\boldsymbol{\beta}) = \frac{1}{n} \mathbf{Z}' (\mathbf{y} - \mathbf{X}\boldsymbol{\beta}) \]
WHERE:
\(\mathbf{Z}\) Instrument matrix of dimension \(n \times L\).
\(\mathbf{X}\) Regressor matrix of dimension \(n \times K\).
\(L\) Total number of available instruments (and moment conditions).
\(K\) Total number of unknown structural parameters in \(\boldsymbol{\beta}\).
\(\hat{\mathbf{g}}(\boldsymbol{\beta})\) The \(L \times 1\) sample moment vector.

2. Identification Regimes: Just vs. Overidentified Systems

The relationship between the number of moment conditions \(L\) and the number of parameters \(K\) governs the mathematical solvability of the system:

Underidentified (\(L < K\))

Fewer moment equations than parameters. Infinite parameter vectors solve the system; \(\boldsymbol{\beta}\) cannot be uniquely identified without further economic assumptions.

Just-Identified (\(L = K\))

Exactly as many moment equations as parameters. We can set every sample moment strictly to zero: \(\mathbf{Z}'(\mathbf{y} - \mathbf{X}\hat{\boldsymbol{\beta}}) = \mathbf{0}\).

Overidentified (\(L > K\))

More moment equations than parameters. In finite samples, no single \(\boldsymbol{\beta}\) can set all \(L\) moments simultaneously to zero. GMM is required to optimally compromise.

SPECIAL CASE · L = K

Just-Identified GMM Collapses to Standard IV

\[ \mathbf{Z}' (\mathbf{y} - \mathbf{X}\hat{\boldsymbol{\beta}}) = \mathbf{0} \implies \mathbf{Z}'\mathbf{y} = \mathbf{Z}'\mathbf{X}\hat{\boldsymbol{\beta}} \implies \hat{\boldsymbol{\beta}}_{IV} = (\mathbf{Z}'\mathbf{X})^{-1} \mathbf{Z}'\mathbf{y} \]
WHERE:
\(\hat{\boldsymbol{\beta}}_{IV}\) The standard Instrumental Variables estimator.
\(\mathbf{Z}'\mathbf{X}\) A square \(K \times K\) matrix, invertible under the instrument relevance rank condition.

Key Result: When the number of instruments equals the number of regressors (\(L = K\)), GMM simplifies to the classical IV estimator without requiring any weighting matrix!

3. The Overidentified Case (\(L > K\)) & the Weighting Matrix

When \(L > K\), we have an overdetermined system: \(L\) equations trying to solve for \(K\) parameters. Because random sampling error makes it impossible to satisfy all \(L\) equations exactly, we construct an objective function that minimizes the weighted quadratic distance of the moment vector from zero:

GMM CRITERION · QUADRATIC FORM

The Quadratic GMM Objective and Estimator

\[ Q_n(\boldsymbol{\beta}) = \hat{\mathbf{g}}(\boldsymbol{\beta})' \mathbf{W} \hat{\mathbf{g}}(\boldsymbol{\beta}) \] \[ \hat{\boldsymbol{\beta}}_{GMM} = \arg\min_{\boldsymbol{\beta}} \left[ \frac{1}{n} \mathbf{Z}' (\mathbf{y} - \mathbf{X}\boldsymbol{\beta}) \right]' \mathbf{W} \left[ \frac{1}{n} \mathbf{Z}' (\mathbf{y} - \mathbf{X}\boldsymbol{\beta}) \right] \]
WHERE:
\(Q_n(\boldsymbol{\beta})\) The scalar quadratic GMM loss function to be minimized.
\(\mathbf{W}\) A symmetric, positive semi-definite \(L \times L\) weighting matrix.

To solve this minimization, we differentiate \(Q_n(\boldsymbol{\beta})\) with respect to \(\boldsymbol{\beta}\) and set the gradient to zero. The source notes:

SPECIAL CHOICE · 2SLS AS GMM

Weighting Matrix \(\mathbf{W} = (\mathbf{Z}'\mathbf{Z})^{-1}\) Derives 2SLS

\[ \mathbf{W} = (\mathbf{Z}'\mathbf{Z})^{-1} \] \[ \hat{\boldsymbol{\beta}}_{GMM} = \left[ \mathbf{X}'\mathbf{Z} (\mathbf{Z}'\mathbf{Z})^{-1} \mathbf{Z}'\mathbf{X} \right]^{-1} \mathbf{X}'\mathbf{Z} (\mathbf{Z}'\mathbf{Z})^{-1} \mathbf{Z}'\mathbf{y} = \hat{\boldsymbol{\beta}}_{2SLS} \]
WHERE:
\((\mathbf{Z}'\mathbf{Z})^{-1}\) Instrument sample cross-product inverse, scaling moments by instrument variances.
\(\hat{\boldsymbol{\beta}}_{2SLS}\) The classical Two-Stage Least Squares estimator.

💡 Core Pedagogical Intuition

GMM generalizes Instrumental Variables to allow for multiple (possibly correlated) instruments. The weighting matrix \(\mathbf{W}\) adjusts for correlation between instruments to improve estimation efficiency. When \(\mathbf{W} = (\mathbf{Z}'\mathbf{Z})^{-1}\), GMM exactly reproduces Two-Stage Least Squares!

🔎 WHAT TO NOTICE

When you increase the weight \(w_1\) on Instrument 1, the bowl shifts leftward toward 1.0. A higher weight forces GMM to prioritize satisfying that specific instrument's moment condition.

◆ WHY IT MATTERS

In overidentified models, no parameter value sets all moments to zero simultaneously. The choice of \(\mathbf{W}\) dictates how much weight each moment gets in the compromise, directly impacting efficiency.

📊 ECONOMETRIC INTERPRETATION

The GMM estimator minimizes weighted squared moment discrepancies: \(\hat{\beta} = (\sum w_j \beta^{(j)}) / (\sum w_j)\). Optimal GMM assigns larger weights to moments with smaller variance.

5. Quick Knowledge Check

CONCEPT CHECK Overidentification

Why is a weighting matrix \(\mathbf{W}\) necessary when \(L > K\), but unnecessary when \(L = K\)?

Hint: Think about the number of equations versus the number of unknowns. When can a system be solved exactly?

Solution: When \(L = K\), we have exactly as many equations as parameters; we can set every sample moment strictly to zero (\(\hat{\mathbf{g}}(\boldsymbol{\beta}) = \mathbf{0}\)), which uniquely solves for \(\hat{\boldsymbol{\beta}}_{IV}\) regardless of \(\mathbf{W}\). When \(L > K\), the system is overdetermined: no single \(\boldsymbol{\beta}\) can set all \(L\) moments to zero simultaneously. A weighting matrix \(\mathbf{W}\) is mandatory to define a scalar criterion \(Q_n(\boldsymbol{\beta}) = \hat{\mathbf{g}}'\mathbf{W}\hat{\mathbf{g}}\) and trade off competing moment discrepancies.

Lesson 17.5 Summary

GMM seamlessly accommodates multiple instruments through quadratic moment weighting:

  • Instrument Moments: When \(\mathbf{Z} \ne \mathbf{X}\), sample moments take the form \(\hat{\mathbf{g}}(\boldsymbol{\beta}) = \frac{1}{n}\mathbf{Z}'(\mathbf{y} - \mathbf{X}\boldsymbol{\beta})\).
  • Identification Taxonomy: Underidentified (\(L < K\)), Just-identified (\(L = K \implies \hat{\boldsymbol{\beta}}_{IV}\)), and Overidentified (\(L > K\)).
  • GMM Criterion: Overidentified systems minimize \(Q_n(\boldsymbol{\beta}) = \hat{\mathbf{g}}'\mathbf{W}\hat{\mathbf{g}}\) where \(\mathbf{W}\) is positive semi-definite.
  • 2SLS Equivalence: Setting \(\mathbf{W} = (\mathbf{Z}'\mathbf{Z})^{-1}\) derives the standard Two-Stage Least Squares estimator.
