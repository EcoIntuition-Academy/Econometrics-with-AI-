LESSON 1.5 CLRM Assumptions (Part 1)

CLRM: Linearity & Full Rank

Why "linear" in econometrics does not mean a straight line in variables, and how the full rank condition guarantees that OLS coefficients can be uniquely computed.

🎯 Learning Objectives

  • Navigate the 6 foundational assumptions of the Classical Linear Regression Model (CLRM).
  • Distinguish between linearity in parameters vs. linearity in variables.
  • Understand the Full Rank condition \(\text{rank}(X) = k\) and sample size requirement \(n \ge k\).
  • Explain why perfect multicollinearity makes \((X'X)^{-1}\) undefined, preventing coefficient identification.

1. Assumption A1: Linearity in Parameters

Assumption A1 Linearity in Unknown Parameters
\[ y = X\beta + \varepsilon = \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_k x_k + \varepsilon \]
STRUCTURAL REQUIREMENT:
\(\beta_j\)Parameters must enter with power 1; cannot be multiplied, divided, or exponentiated
\(x_j\)Variables may be arbitrarily transformed: polynomials (\(x^2\)), logs (\(\ln x\)), interactions (\(x_1 x_2\))

Why Does It Matter?

Because parameters enter linearly, the first-order conditions \(\partial S / \partial \beta = 0\) form a system of linear algebraic equations (the Normal Equations). This guarantees a simple, closed-form matrix solution \(\hat{\beta} = (X'X)^{-1}X'y\) with unique global properties.

What Happens If It Fails?

If the model is non-linear in parameters (e.g. \(y = \beta_1 x^{\beta_2} + \varepsilon\)), standard linear OLS cannot be applied. You must resort to Non-linear Least Squares (NLS), numerical optimization, or log transformations.

Linear in Parameters \(\neq\) Linear in Variables!

The variables \(x\) and \(y\) can undergo any known mathematical transformation (powers, logarithms, interactions, square roots, trigs). As long as each unknown \(\beta_j\) appears with power 1 and is not multiplied or divided by another \(\beta\), the model is linear!

✓ Perfectly Valid Linear Models:
  • \(y = \beta_1 + \beta_2 x_2 + \varepsilon\) (Standard straight line)
  • \(y = \beta_1 + \beta_2 \ln(x_2) + \varepsilon\) (Logarithmic curve)
  • \(y = \beta_1 + \beta_2 x_2 + \beta_3 x_2^2 + \varepsilon\) (Quadratic parabola)
  • \(\ln(y) = \beta_1 + \beta_2 x_2 + \varepsilon\) (Exponential curve)
  • \(y = \beta_1 + \beta_2 (x_2 \cdot x_3) + \varepsilon\) (Interaction effect)
✗ Non-Linear in Parameters:
  • \(y = \beta_1 + x_2^{\beta_2} + \varepsilon\) (\(\beta_2\) is in the exponent)
  • \(y = \beta_1 + \beta_2^2 x_2 + \varepsilon\) (\(\beta_2\) is squared)
  • \(y = \frac{\beta_1 x_2}{\beta_2 + x_2} + \varepsilon\) (\(\beta_2\) is in the denominator)
  • \(y = \beta_1 + \beta_1 \beta_2 x_2 + \varepsilon\) (Product of parameters)

2. Assumption A2: Full Column Rank

Assumption A2 Full Column Rank & Invertibility
\[ \text{rank}(X) = k \iff \det(X'X) \neq 0 \implies (X'X)^{-1} \text{ exists uniquely} \]
IDENTIFICATION CONDITIONS:
\(n \ge k\)Sample size must be greater than or equal to the number of parameters
\(\text{rank}(X) = k\)No perfect multicollinearity: no column is an exact linear combination of others

Why Does It Matter?

A fundamental theorem of linear algebra states that if an \(n \times k\) matrix \(X\) has full column rank \(k\), then the \(k \times k\) product matrix \(X'X\) is positive definite, symmetric, and strictly invertible!

What Happens If It Fails?

If \(\text{rank}(X) < k\), then \(\text{det}(X'X) = 0\). The matrix is singular. \((X'X)^{-1}\) does not exist. The Normal Equations have an infinite continuum of solutions, and OLS cannot identify individual coefficients!

Example of Perfect Multicollinearity: The Dummy Variable Trap

Suppose an analyst defines three regressors:

  • \(x_1 = 1\) (Intercept constant)
  • \(x_2 = \text{Female}\) (1 if female, 0 if male)
  • \(x_3 = \text{Male}\) (1 if male, 0 if female)

Notice that for every single observation in the sample:

$$x_2 + x_3 = 1 = x_1 \implies x_1 - x_2 - x_3 = 0$$

Column 1 is an exact linear sum of Columns 2 and 3. In matrix terms, the columns are linearly dependent. OLS cannot distinguish whether a high wage is caused by being male, being female, or the general baseline intercept! Econometric software will automatically drop one dummy variable or report an error.

Geometric Vector Intuition of Column Space Linear Independence
Full Rank (Independent Vectors)
Vectors point in different directions, spanning a full 2D plane. Unique solution exists.
Rank Deficient (Collinear)
Vectors lie along the exact same line. Redundant dimension; X'X cannot be inverted.
⚠️ Common Student Mistake
MISCONCEPTION: "High correlation between two regressors (e.g. \(r = 0.85\)) violates Assumption A2 and makes OLS impossible to compute."
CORRECTION: Assumption A2 forbids perfect multicollinearity (\(r = 1.0\)), which prevents matrix inversion. High (imperfect) multicollinearity simply increases standard errors, making estimates less precise, but \((X'X)^{-1}\) still exists and OLS remains unbiased!
🤖 AI Insight High Dimensions in Modern AI: The \(k > n\) Problem

In genomic econometrics or text analysis, you might have \(n = 200\) patients but \(k = 10,000\) genetic markers. Because \(\text{rank}(X) \le \min(n, k) = 200 < 10,000\), Assumption A2 is catastrophically violated. Linear OLS breaks down completely. Econometricians use Lasso, Ridge (penalized regression), or Principal Components to restore full rank!

Quick Knowledge Check

Question: A researcher estimates the model: $$\text{Wage}_i = \beta_1 + \beta_2 \text{Age}_i + \beta_3 \text{BirthYear}_i + \varepsilon_i$$ All observations are measured in survey year 2024. Can OLS estimate \(\beta_1, \beta_2, \beta_3\)? Which CLRM assumption fails, and why?

Write out the exact identity relating Age, BirthYear, and survey year 2024.

Solution:
- No, OLS cannot estimate this model.
- Assumption A2 (Full Rank) fails completely. In a single cross-section in 2024, by definition: $$\text{Age}_i + \text{BirthYear}_i = 2024 \cdot (\text{Intercept}_i)$$ Because \(\text{Age} + \text{BirthYear} - 2024(1) = 0\), the columns are perfectly collinear. The matrix \(X'X\) is singular, \((X'X)^{-1}\) does not exist, and OLS cannot separate the effect of aging from the effect of the cohort of birth.

Lesson 1.5 Summary

Linear regression allows arbitrary transformations of variables as long as parameters enter linearly (A1). To ensure a unique mathematical solution exists, the design matrix must have full column rank \(\text{rank}(X)=k\) (A2), ruling out perfect multicollinearity.
