Confidence Intervals & Large-Sample Hypothesis Testing

Because the OLS estimator is asymptotically normal, coefficient uncertainty can be standardized using estimated standard errors. Discover the large-sample 99% and 95% confidence intervals, understand why \(t\)-statistics converge to standard normal \(z\)-statistics, and conduct rigorous two-tailed hypothesis tests.

OBJECTIVES Learning Objectives

  • Formulate the standardized test statistic \(z_k = \frac{\hat{\beta}_k - \beta_k}{\sqrt{\sigma^2 S_{kk}}}\) and inspect its denominator.
  • Derive the 99% large-sample confidence interval using critical values \(\pm 2.576\).
  • Follow the transition from theoretical \(\sigma^2\) to feasible \(s^2\), establishing why \(t_k \xrightarrow{d} z_k\).
  • Contrast heavy-tailed finite-sample \(t\) distributions with the standard normal distribution without inventing arbitrary sample-size thresholds.
  • Conduct large-sample two-sided hypothesis tests at \(\alpha = 0.05\) using critical values \(\pm 1.96\), strictly adhering to "Reject" vs. "Fail to Reject" language.

1. The Standardized z Statistic

Because \(\hat{\beta}_{\text{OLS}}\) is asymptotically normal, testing a hypothesis about any single coefficient \(\beta_k\) begins by standardizing the estimation error by its true standard deviation:

Key Equation: Standardized z Statistic
\[z_k = \frac{\hat{\beta}_k - \beta_k}{\sqrt{\sigma^2 S_{kk}}} \xrightarrow{d} \mathcal{N}(0, 1)\]
Where \(S_{kk}\) denotes the \(k\)-th diagonal element of \((X'X)^{-1}\). The denominator \(\sqrt{\sigma^2 S_{kk}}\) is the exact theoretical standard deviation of \(\hat{\beta}_k\).

For a 99% confidence interval (two-tailed significance level \(\alpha = 0.01\)), the critical values from the standard normal cumulative distribution \(\Phi(z)\) are:

\(\Phi^{-1}(0.005) = -2.576, \quad \Phi^{-1}(0.995) = +2.576\)
Key Equation: 99% Confidence Interval
\[\Pr\left( \hat{\beta}_k - 2.576 \sqrt{\sigma^2 S_{kk}} \;\le\; \beta_k \;\le\; \hat{\beta}_k + 2.576 \sqrt{\sigma^2 S_{kk}} \right) = 0.99\]
General formula: \(\text{Point Estimate} \pm \text{Critical Value} \times \text{Standard Error}\).

2. Feasible Inference: Replacing Unknown σ² with s²

In practice, the true disturbance variance \(\sigma^2\) is unknown. Large-sample theory makes inference operational by substituting consistent variance estimators:

The Three-Stage Transition to Feasible Inference

STAGE 1 True disturbance variance \(\sigma^2\) is unobserved in empirical reality.
STAGE 2 Estimate \(\sigma^2\) consistently using the sample residual variance: \(s^2 = \frac{e'e}{n-k}\).
STAGE 3 Form the feasible test statistic: \(t_k = \frac{\hat{\beta}_k - \beta_k}{\sqrt{s^2 S_{kk}}}\).

Because \(s^2 \xrightarrow{p} \sigma^2\) by consistency, Slutsky's theorem guarantees that for large \(n\):

\(t_k \xrightarrow{d} z_k \sim \mathcal{N}(0, 1)\)

Therefore, in large samples, the exact same normal critical value \(\pm 2.576\) applies to the feasible confidence interval:

\[\Pr\left( \hat{\beta}_k - 2.576 \sqrt{s^2 S_{kk}} \;\le\; \beta_k \;\le\; \hat{\beta}_k + 2.576 \sqrt{s^2 S_{kk}} \right) = 0.99\]

3. Finite-Sample t vs. Large-Sample Normal: The Degrees-of-Freedom Effect

How does the large-sample normal approximation compare to finite-sample Student's \(t\) distributions? Consider the classic comparative degrees-of-freedom illustration:

Illustrative Example: Degrees of Freedom = 50

If sample size is smaller—such as degrees of freedom \(n - k = 50\)—the critical value from the Student's \(t_{50}\) distribution is slightly higher: \(2.678\) instead of \(2.576\):

\(\Pr\left( \hat{\beta}_k - 2.678 \sqrt{s^2 S_{kk}} \;\le\; \beta_k \;\le\; \hat{\beta}_k + 2.678 \sqrt{s^2 S_{kk}} \right) = 0.99\)

Econometric Intuition: Smaller samples = thicker tails in the \(t\)-distribution = wider confidence intervals. The wider interval directly accounts for sampling uncertainty in estimating the unknown \(\sigma^2\) with \(s^2\).

GUARDRAIL Methodological Guardrail: No Magic Thresholds

Treat \(n - k = 50\) strictly as an illustrative example. Econometricians do not use arbitrary rules like "\(n < 30\) is small, \(n \ge 30\) is large". The convergence of \(t_{n-k}\) to \(\mathcal{N}(0, 1)\) is smooth and continuous as \(n \to \infty\).

4. Testing the Null Hypothesis: \(H_0: \beta_k = 0\)

Consider testing the standard null hypothesis that regressor \(k\) has zero population effect:

\(H_0: \beta_k = 0 \quad \text{versus} \quad H_1: \beta_k \neq 0\)

Under the null hypothesis, the test statistic simplifies to:

\(t_k = \frac{\hat{\beta}_k - 0}{\sqrt{s^2 S_{kk}}} = \frac{\hat{\beta}_k}{\operatorname{SE}(\hat{\beta}_k)}\)

Intuitive Meaning: The test statistic asks: "How many estimated standard errors away from zero is the sample estimate \(\hat{\beta}_k\)?"

Key Equation: Two-Tailed 5% Rejection Rule
\[\Pr\left( \left| \frac{\hat{\beta}_k - \beta_k}{\sqrt{s^2 S_{kk}}} \right| > 1.96 \right) = 0.05\]
If the null hypothesis is true, there is only a 5% chance of observing a test statistic outside the range \([-1.96, +1.96]\).

Strict Decision Terminology

If \(|t_k| > 1.96\):
REJECT \(H_0\)

We reject the null hypothesis at the 5% significance level. The empirical evidence is inconsistent with \(\beta_k = 0\).

If \(|t_k| \le 1.96\):
FAIL TO REJECT \(H_0\)

We fail to reject the null hypothesis. We NEVER say "Accept \(H_0\)"; we merely lack sufficient evidence to disprove zero.

QUICK CHECK Reject vs. Accept

In an estimated regression with \(n = 1000\), an econometrician tests \(H_0: \beta_1 = 0\) and obtains a test statistic \(t = 1.15\). At the 5% level (\(\text{critical} = \pm 1.96\)), what is the proper conclusion? Can the econometrician claim: "We accept the null hypothesis that the true coefficient is zero"?

Show Answer & Explanation
ANSWER: Fail to reject \(H_0\). No, one must NEVER claim to "accept" the null hypothesis!

WHY? Failing to reject \(H_0\) simply means the data do not provide sufficiently strong statistical evidence to rule out zero. The true parameter could be \(0.05\) or \(-0.02\). In scientific hypothesis testing, absence of evidence is not evidence of absence; we conclude: "We fail to reject \(H_0\) at the 5% significance level."
SUMMARY

What You Should Now Understand

  • The standardized statistic is \(z_k = \frac{\hat{\beta}_k - \beta_k}{\sqrt{\sigma^2 S_{kk}}}\), where \(\sqrt{\sigma^2 S_{kk}}\) is the true standard error.
  • The large-sample 99% confidence interval uses normal critical values \(\pm 2.576\): \(\hat{\beta}_k \pm 2.576 \operatorname{SE}(\hat{\beta}_k)\).
  • Replacing unknown \(\sigma^2\) with sample estimate \(s^2\) yields the feasible statistic \(t_k = \frac{\hat{\beta}_k - \beta_k}{\sqrt{s^2 S_{kk}}}\). By Slutsky's theorem, \(t_k \xrightarrow{d} z_k\) as \(n \to \infty\).
  • In smaller samples (e.g., \(n - k = 50\)), Student's \(t\) distributions have heavier tails (\(t_{50, 0.005} = 2.678\)), requiring wider intervals to account for uncertainty in \(s^2\).
  • For a two-sided 5% test of \(H_0: \beta_k = 0\), the decision rule rejects when \(|t_k| > 1.96\). Always use "Reject" or "Fail to Reject"—never "Accept".
