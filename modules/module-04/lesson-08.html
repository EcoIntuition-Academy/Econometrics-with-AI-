Wald Testing, Classical vs Asymptotic Inference & Robust SE

How do we test restrictions on nonlinear functions of parameters? 1. The Wald Test for Nonlinear Restrictions

In linear regression (Module 3), we used \(t\)-tests for single linear hypotheses and \(F\)-tests for multiple linear restrictions \(R\beta = r\).

The Wald test generalizes hypothesis testing to arbitrary (possibly nonlinear) functions of parameter vectors. In formal large-sample theory:

Definition: The Wald Test
\[H_0: g(\theta) = 0 \quad \text{versus} \quad H_1: g(\theta) \neq 0\]
Where \(g(\cdot)\) is a continuously differentiable (possibly nonlinear) function.

Under the null hypothesis, the Wald test statistic is:

Key Equation: Wald Test Statistic
\[W = \frac{\left[ g(\hat{\theta}) \right]^2}{\widehat{\operatorname{Var}}(g(\hat{\theta}))} \xrightarrow{d} \chi^2_1\]
The squared deviation of the restriction from zero, scaled by the estimated variance of the restriction obtained via the Delta Method.

Intuition: Distance in Standard Error Units

"The Wald test measures how far \(g(\hat{\theta})\) is from 0 in standard error units. If it's far enough, we reject \(H_0\). It generalizes the \(t\)-test to nonlinear hypotheses."

The Fundamental Connection: t² = W ~ χ²₁

For a single scalar linear restriction \(g(\theta) = \hat{\beta}_k - 0\): \[t_k^2 = \left( \frac{\hat{\beta}_k}{\operatorname{SE}(\hat{\beta}_k)} \right)^2 = \frac{\hat{\beta}_k^2}{\operatorname{Var}(\hat{\beta}_k)} = W \sim \chi^2_1\] Because the square of a standard normal random variable is distributed as Chi-Square with 1 degree of freedom (\(Z^2 \sim \chi^2_1\)), the squared \(t\)-statistic is an exact special case of the Wald statistic!

2. Worked Example: Testing g(θ) = β₂² = 0

Consider the following empirical example:

Given Example Values

Let \(\hat{\theta} = \hat{\beta}_2\) and \(g(\theta) = \beta_2^2\). Suppose:

\(\hat{\beta}_2 = 2.0, \quad \operatorname{SE}(\hat{\beta}_2^2) = 2.0 \implies \widehat{\operatorname{Var}}(\hat{\beta}_2^2) = 2.0^2 = 4.0\)

We compute the Wald test statistic for \(H_0: \beta_2^2 = 0\):

\[W = \frac{[g(\hat{\theta})]^2}{\widehat{\operatorname{Var}}(g(\hat{\theta}))} = \frac{(2)^2}{2^2} = \frac{4}{4} = 1.0\]

We compare \(W = 1.0\) against the 5% critical value from the \(\chi^2_1\) distribution: \[\chi^2_{1, \, 0.95} = 3.841\]

DECISION: Since \(W = 1.0 \le 3.841\), we FAIL TO REJECT the null hypothesis that \(\beta_2^2 = 0\) at the 5% level.

4. Synthesis: Finite-Sample vs. Large-Sample Framework

The following two foundational summary tables contrast finite-sample (classical) econometrics with large-sample (asymptotic) theory:

Table 1: Estimator Properties Summary

Property Finite Sample (Classical) Large Sample (Asymptotic)
Unbiasedness \(\mathbb{E}[\hat{\theta}] = \theta\) (Required) Not required (Asymptotic unbiasedness / consistency dominates)
Consistency Not guaranteed in finite samples \(\operatorname{plim}_{n \to \infty} \hat{\theta}_n = \theta\) (Guaranteed)
Efficiency Minimum Variance Linear Unbiased (BLUE / MVUE) Smallest Asymptotic Variance (CAN Class)
Normality \(\hat{\theta} \sim \mathcal{N}(\theta, \operatorname{Var})\) (Needs normal \(\varepsilon_i\)) \(\hat{\theta} \xrightarrow{a} \mathcal{N}(\theta, \operatorname{AsyVar})\) (Via CLT; no normal \(\varepsilon\) needed)

Table 2: Inference Framework Comparison

Inference Aspect Small Sample (Classical) Large Sample (Asymptotic)
Error Assumption Exact Normality: \(\varepsilon \mid X \sim \mathcal{N}(0, \sigma^2 I)\) Finite Variance & Independence (Non-normality permitted)
Estimator Distribution Exact \(t_{n-k}\), exact \(F_{q, n-k}\) Approximate Normal (\(z\)), Approximate \(\chi^2_q\)
Variance Estimator \(s^2(X'X)^{-1}\) \(s^2(X'X)^{-1}\) (Justified asymptotically by CLT)
Critical Values \(t_{n-k}, \; F_{q, n-k}\) \(z = \pm 1.96, \; \chi^2_q\)
Robust to Heteroskedasticity? NO (Exact inference fails) YES (With robust standard errors)

5. Preview: The Motivation for Robust Standard Errors

Modern empirical research emphasizes the practical reality of heteroskedasticity:

ROBUST INFERENCE

Why Classical Standard Errors Fail Under Heteroskedasticity

  • Homoskedasticity assumption: The classical formula \(s^2(X'X)^{-1}\) assumes constant error variance across all individuals: \(\operatorname{Var}(\varepsilon_i \mid x_i) = \sigma^2\).
  • The danger of violation: If error variance varies across observations (e.g., wealthy households exhibit higher consumption variance than poor households), \(s^2(X'X)^{-1}\) is inconsistent and typically underestimates true parameter uncertainty!
  • The large-sample solution: In large samples, we can estimate standard errors that are robust to arbitrary heteroskedasticity (the White / Huber sandwich estimator): \[\widehat{\operatorname{Var}}_{\text{robust}}(\hat{\beta}) = (X'X)^{-1} \left( \sum_{i=1}^n e_i^2 x_i x_i' \right) (X'X)^{-1}\]
  • Asymptotic validity: Large-sample theory gives us the mathematical power to conduct valid hypothesis tests even when classical equal-variance assumptions break down.

6. Module 4 Knowledge Map & Complete Review (15 Core Concepts)

Review all 15 core theoretical and practical milestones established across Module 4:

1. Convergence in Probability

\(\lim_{n \to \infty} \Pr(|x_n - c| > \varepsilon) = 0\). Mass concentrates around constant \(c\).

2. Epsilon (ε) Distinction

The \(\varepsilon > 0\) in plim is a distance tolerance, NOT the regression disturbance \(\varepsilon_i\).

3. Consistency of Estimators

\(\operatorname{plim}_{n \to \infty} \hat{\theta}_n = \theta\). Asymptotic property; does not mean zero finite-sample error.

4. Limit Moment Matrix Q

\(\lim \frac{X'X}{n} = Q\). Sample average of regressor cross-products converges to positive definite \(Q\).

5. Grenander Regularity

No series of zeros, no single observation dominates, and \(X\) maintains full column rank.

6. Consistency of OLS Proof

\(\hat{\beta} - \beta = \left(\frac{X'X}{n}\right)^{-1}\left(\frac{X'\varepsilon}{n}\right) \xrightarrow{p} Q^{-1}\mathbf{0} = \mathbf{0}\).

7. Asymptotic Normality of OLS

\(\hat{\beta}_{\text{OLS}} \xrightarrow{a} \mathcal{N}\left(\beta, \frac{\sigma^2}{n}Q^{-1}\right)\). CLT holds without normal errors.

8. Variance vs Standard Error

Variance is in squared units; \(\operatorname{SE} = \sqrt{\operatorname{Var}}\) is in linear units and used in all CIs.

9. CAN Estimators & Efficiency

Consistent & Asymptotically Normal. Efficient CAN has smallest asymptotic covariance matrix.

10. OLS vs MLE Comparison

Normal errors \(\implies\) OLS = MLE. Non-normal errors \(\implies\) correctly specified MLE is more efficient.

11. Standardized z & Feasible t

\(t_k = \frac{\hat{\beta}_k - \beta_k}{\sqrt{s^2 S_{kk}}} \xrightarrow{d} z_k\). 99% CI uses \(\pm 2.576\); 5% test uses \(\pm 1.96\).

12. The Delta Method

\(g(\hat{\theta}) \xrightarrow{a} \mathcal{N}(g(\theta), \frac{1}{n}[g'(\theta)]^2\sigma^2)\). First derivative scales uncertainty.

13. Slutsky’s Theorem

Allows algebraic sum, product, and ratio combinations of \((\xrightarrow{d})\) and \((\xrightarrow{p})\) sequences.

14. The Wald Test & t² Equivalence

\(W = \frac{[g(\hat{\theta})]^2}{\operatorname{Var}(g)} \sim \chi^2_1\). For scalar tests, \(t^2 = W \sim \chi^2_1\).

15. Robust Standard Errors Motivation

When \(\operatorname{Var}(\varepsilon_i \mid x_i) \neq \sigma^2\), sandwich covariance estimators maintain valid large-sample inference.

QUICK CHECK Wald Test Equivalence

In a large sample, an empirical study reports a \(t\)-statistic of \(t = -2.50\) for the hypothesis \(H_0: \beta_1 = 0\). What is the corresponding Wald statistic \(W\), and what is the test conclusion at the 5% level (\(\chi^2_{1, 0.95} = 3.841\))?

Show Answer & Explanation
ANSWER: \(W = (-2.50)^2 = 6.25\). Conclusion: REJECT \(H_0\).

WHY?
  1. For a single restriction, \(t^2 = W\). Squaring \(-2.50\) gives \(W = 6.25\).
  2. Because \(6.25 > 3.841\), the Wald statistic falls into the 5% rejection region.
  3. Notice this matches the two-sided \(z\)-test: \(|-2.50| > 1.96 \implies \text{Reject } H_0\). The tests are completely identical!
SUMMARY

What You Should Now Understand (Module 4 Capstone)

  • The Wald test evaluates hypotheses on (possibly nonlinear) parameter functions: \(W = \frac{[g(\hat{\theta})]^2}{\widehat{\operatorname{Var}}(g(\hat{\theta}))} \xrightarrow{d} \chi^2_1\).
  • For a single linear hypothesis, \(t^2 = W \sim \chi^2_1\). In the source example (\(g = 2, \operatorname{SE} = 2\)), \(W = 1.0 < 3.841\), leading to "Fail to Reject \(H_0\)".
  • Large-sample theory trades finite-sample properties like unbiasedness for consistency and asymptotic normality, allowing valid inference without assuming normal errors.
  • Critical values transition from Student's \(t_{n-k}\) and \(F\) distributions to standard normal \(z\) and \(\chi^2\) distributions.
  • Violations of homoskedasticity motivate White / Huber robust standard errors, which remain consistent in large samples without assuming equal error variance.
