LESSON 11.6 Matrix Estimation

IV in Matrix Form: The Exactly Identified Case

Formulate OLS and IV in matrix notation for the square system where the number of instruments equals the number of regressors, derive their bias terms, and prove consistency under instrument validity.

🎯

Learning Objectives

  • Express the linear regression model in matrix notation: \(\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}\).
  • Derive the OLS estimator \(\hat{\boldsymbol{\beta}}_{\text{OLS}} = \boldsymbol{\beta} + (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\boldsymbol{\varepsilon}\) and identify the OLS bias term.
  • Specify the exactly identified IV system (\(K = L\)) with square, invertible cross-product matrix \(\mathbf{Z}'\mathbf{X}\).
  • Derive the IV estimator \(\hat{\boldsymbol{\beta}}_{\text{IV}} = (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'\mathbf{y} = \boldsymbol{\beta} + (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'\boldsymbol{\varepsilon}\).
  • Prove that the IV estimator is consistent when the orthogonality condition \(\mathbb{E}[\mathbf{Z}'\boldsymbol{\varepsilon}] = \mathbf{0}\) holds.
  • Compare the algebraic structure and bias terms of OLS versus IV side-by-side.
01
OLS Foundation

Matrix Formulation of OLS Bias

Let the regression model be written in compact matrix notation:

\[\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}\]
Matrix Dimensions
\(\mathbf{y} \in \mathbb{R}^{n \times 1}\) \(\mathbf{X} \in \mathbb{R}^{n \times K}\) \(\boldsymbol{\beta} \in \mathbb{R}^{K \times 1}\) \(\boldsymbol{\varepsilon} \in \mathbb{R}^{n \times 1}\)

The standard Ordinary Least Squares estimator is:

\[\hat{\boldsymbol{\beta}}_{\text{OLS}} = (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{y}\]

Substituting the true structural data generating process \(\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}\) into the estimator yields:

\[\begin{aligned} \hat{\boldsymbol{\beta}}_{\text{OLS}} &= (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'(\mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}) \\ &= (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{X}\boldsymbol{\beta} + (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\boldsymbol{\varepsilon} \\ &= \boldsymbol{\beta} + (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\boldsymbol{\varepsilon} \end{aligned}\]

THE OLS PROBLEM: CORRELATED REGRESSOR ERROR

Taking the mathematical expectation:

\[\mathbb{E}[\hat{\boldsymbol{\beta}}_{\text{OLS}}] = \boldsymbol{\beta} + \mathbb{E}[(\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\boldsymbol{\varepsilon}]\]

The OLS estimator is unbiased if and only if \(\mathbb{E}[\mathbf{X}'\boldsymbol{\varepsilon}] = \mathbf{0}\). If regressors \(\mathbf{X}\) are endogenous (\(\mathbb{E}[\mathbf{X}'\boldsymbol{\varepsilon}] \ne \mathbf{0}\)), the bias term does not vanish, and OLS consistently fails to recover \(\boldsymbol{\beta}\).

02
Just-Identified Case

The Exactly Identified IV Estimator (\(K = L\))

Now suppose we have an instrument matrix \(\mathbf{Z}\) containing exactly the same number of columns as \(\mathbf{X}\) (\(K = L\)):

Matrix Dimensions (\(K = L\))
\(\mathbf{X} \in \mathbb{R}^{n \times K}\) \(\mathbf{Z} \in \mathbb{R}^{n \times K}\) \(\mathbf{Z}'\mathbf{X} \in \mathbb{R}^{K \times K}\) (Square) \(\mathbf{Z}'\mathbf{y} \in \mathbb{R}^{K \times 1}\)

Because \(\mathbf{Z}'\mathbf{X}\) is a square \(K \times K\) matrix, it can be directly inverted (provided the relevance assumption holds and \(\text{rank}(\mathbf{Z}'\mathbf{X}) = K\)).

DEFINITION: EXACTLY IDENTIFIED IV ESTIMATOR

When \(K = L\), the Instrumental Variables estimator in matrix notation is:

\[\hat{\boldsymbol{\beta}}_{\text{IV}} = (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'\mathbf{y}\]
03
Derivation Journey

Deriving the Consistency of \(\hat{\boldsymbol{\beta}}_{\text{IV}}\)

DERIVATION GOAL

Prove that \(\hat{\boldsymbol{\beta}}_{\text{IV}}\) is Consistent Under Instrument Validity

STEP 1: SUBSTITUTE DATA GENERATING PROCESS

Substitute \(\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}\) into the IV estimator formula:

\[\hat{\boldsymbol{\beta}}_{\text{IV}} = (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'(\mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon})\]
STEP 2: EXPAND MATRIX PRODUCTS

Distribute \(\mathbf{Z}'\) across the sum:

\[\hat{\boldsymbol{\beta}}_{\text{IV}} = (\mathbf{Z}'\mathbf{X})^{-1}(\mathbf{Z}'\mathbf{X})\boldsymbol{\beta} + (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'\boldsymbol{\varepsilon}\]

Since \((\mathbf{Z}'\mathbf{X})^{-1}(\mathbf{Z}'\mathbf{X}) = \mathbf{I}_K\), this simplifies immediately to:

\[\hat{\boldsymbol{\beta}}_{\text{IV}} = \boldsymbol{\beta} + (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'\boldsymbol{\varepsilon}\]
STEP 3: TAKE EXPECTATION & APPLY ORTHOGONALITY

Taking the expectation conditional on instruments \(\mathbf{Z}\):

\[\mathbb{E}[\hat{\boldsymbol{\beta}}_{\text{IV}}] = \boldsymbol{\beta} + (\mathbf{Z}'\mathbf{X})^{-1}\mathbb{E}[\mathbf{Z}'\boldsymbol{\varepsilon}]\]

Because the instruments are valid, \(\mathbb{E}[\mathbf{Z}'\boldsymbol{\varepsilon}] = \mathbf{0}\):

\[\mathbb{E}[\hat{\boldsymbol{\beta}}_{\text{IV}}] = \boldsymbol{\beta}\]
04
Direct Contrast

OLS vs IV: Side-by-Side Comparison

Compare the two estimators directly to see how instrumental variables replaces endogenous regressors \(\mathbf{X}\) in the moment condition:

OLS ESTIMATOR

Biased / Inconsistent
\[\hat{\boldsymbol{\beta}}_{\text{OLS}} = \boldsymbol{\beta} + (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\boldsymbol{\varepsilon}\]
  • Depends on cross-product \(\mathbf{X}'\boldsymbol{\varepsilon}\).
  • If \(\mathbf{X}\) is endogenous, \(\mathbf{X}'\boldsymbol{\varepsilon} \ne \mathbf{0}\).
  • Bias term persists even as sample size \(n \to \infty\).

IV ESTIMATOR (\(K = L\))

Consistent
\[\hat{\boldsymbol{\beta}}_{\text{IV}} = \boldsymbol{\beta} + (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'\boldsymbol{\varepsilon}\]
  • Depends on cross-product \(\mathbf{Z}'\boldsymbol{\varepsilon}\).
  • If \(\mathbf{Z}\) is valid, \(\mathbf{Z}'\boldsymbol{\varepsilon} = \mathbf{0}\) in expectation.
  • Estimator converges to true \(\boldsymbol{\beta}\) as \(n \to \infty\).
Summary from Lecture Notes:

“If X is endogenous, X’ε ≠ 0 &implies; OLS is biased. If Z is valid, Z’ε = 0 &implies; IV is consistent.”

💡

QUICK CHECK

What moment condition replaces the OLS exogeneity requirement in the exactly identified IV derivation?

HINT: In the derivation \(\hat{\boldsymbol{\beta}}_{\text{IV}} = \boldsymbol{\beta} + (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'\boldsymbol{\varepsilon}\), what expectation must equal zero for the second term to vanish?

ANSWER: The instrument orthogonality condition: \(\mathbb{E}[\mathbf{Z}'\boldsymbol{\varepsilon}] = \mathbf{0}\).

WHY? In OLS, consistency requires \(\mathbb{E}[\mathbf{X}'\boldsymbol{\varepsilon}] = \mathbf{0}\). When this fails because \(\mathbf{X}\) is endogenous, the IV estimator replaces the regressor matrix with instrument matrix \(\mathbf{Z}\) in the moment equation. If \(\mathbb{E}[\mathbf{Z}'\boldsymbol{\varepsilon}] = \mathbf{0}\), the bias term \((\mathbf{Z}'\mathbf{X})^{-1}\mathbb{E}[\mathbf{Z}'\boldsymbol{\varepsilon}]\) vanishes, guaranteeing consistent estimation.

📋

What You Should Now Understand

  • In matrix form, OLS decomposes into true \(\boldsymbol{\beta}\) plus the bias term \((\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\boldsymbol{\varepsilon}\).
  • When \(K = L\), the cross-product \(\mathbf{Z}'\mathbf{X}\) is square and invertible, defining the estimator \(\hat{\boldsymbol{\beta}}_{\text{IV}} = (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'\mathbf{y}\).
  • Substituting \(\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}\) yields \(\hat{\boldsymbol{\beta}}_{\text{IV}} = \boldsymbol{\beta} + (\mathbf{Z}'\mathbf{X})^{-1}\mathbf{Z}'\boldsymbol{\varepsilon}\).
  • The orthogonality condition \(\mathbb{E}[\mathbf{Z}'\boldsymbol{\varepsilon}] = \mathbf{0}\) ensures that the IV bias term vanishes, establishing consistency.
  • IV trades off precision for consistency: while OLS has smaller standard errors under exogeneity, IV remains consistent when endogeneity corrupts OLS.
