LESSON 11.5 Identification & Procedure

The General IV / 2SLS Procedure & Identification

Generalize instrumental variables estimation to multiple endogenous regressors and included exogenous controls, master the order condition for identification, and trace the general multi-stage procedure.

🎯

Learning Objectives

  • Define the general regressor partition: endogenous regressors \(X\), included controls \(Z_C\), and excluded instruments \(Z_E\).
  • State and interpret the counting rule for identification (the order condition).
  • Classify econometric specifications into underidentified, exactly identified, and overidentified models.
  • Specify the general First Stage: regressing each endogenous regressor on all included controls and excluded instruments.
  • Specify the general Second Stage: regressing outcome \(y\) on fitted regressors \(\hat{X}\) and included controls \(Z_C\).
  • Recognize why excluded instruments \(Z_E\) must never enter directly into the second-stage structural outcome equation.
01
Model Generalization

The General Econometric Specification

In applied empirical research, regression specifications rarely contain just a single regressor. Real-world models incorporate multiple explanatory variables, baseline covariates, and multiple instruments.

DEFINING THE THREE VARIABLE GROUPS

Following the lecture notes, we partition all variables in the system into three distinct classes:

  • \(X\) (Endogenous Regressors): Explanatory variables that correlate with the regression error \(\varepsilon\) (\(\mathbb{E}[X\varepsilon] \ne 0\)). There are \(K\) such regressors.
  • \(Z_C\) (Included Exogenous Controls): Covariates that belong directly in the outcome equation and are orthogonal to \(\varepsilon\) (e.g., age, gender, regional dummies).
  • \(Z_E\) (Excluded Instruments): External exogenous variables that predict \(X\) but do not belong directly in the outcome equation.

The full set of exogenous instruments available to the econometrician is the combined matrix \(Z = [Z_C, \; Z_E]\) with dimension \(n \times L\), where \(L = \dim(Z_C) + \dim(Z_E)\).

02
Order Condition

Identification: The Counting Rule

Can the causal parameters on endogenous regressors \(X\) be recovered? The fundamental necessary requirement is the order condition for identification:

THE ORDER CONDITION

The system must have at least as many excluded instruments (\(Z_E\)) as endogenous regressors (\(X\)).

\[\dim(Z_E) \ge \dim(X) \quad \iff \quad L \ge K\]

Based on this dimensional comparison, econometric models fall into three categories:

UNDERIDENTIFIED
\[L < K \quad (\# Z_E < \# X)\]

Fewer excluded instruments than endogenous regressors. There are more unknowns than moment conditions. IV estimation is mathematically impossible.

EXACTLY IDENTIFIED
\[L = K \quad (\# Z_E = \# X)\]

Number of excluded instruments exactly equals the number of endogenous regressors. There is a unique solution given by the simple IV estimator.

OVERIDENTIFIED
\[L > K \quad (\# Z_E > \# X)\]

More excluded instruments than endogenous regressors. Provides extra identifying information to improve efficiency; requires Two-Stage Least Squares (2SLS).

03
Estimation Algorithm

The General Two-Stage Procedure

When the order condition is satisfied (\(L \ge K\)), the general two-stage procedure is executed as follows:

FIRST STAGE (Executed for EACH endogenous regressor \(x_i\))

Regress on ALL Exogenous Variables

Regress each endogenous variable \(x_i\) on all included controls \(Z_C\) and all excluded instruments \(Z_E\):

\[x_i = Z_C \pi_1 + Z_E \pi_2 + \nu_i \implies \hat{x}_i\]

Calculate the fitted values \(\hat{x}_i\) for each endogenous variable. These fitted values represent the portion of \(x_i\) generated purely by exogenous variation.

SECOND STAGE (Structural Outcome Equation)

Regress y on Fitted \(\hat{x}\) and \(Z_C\)

Regress outcome variable \(y\) on all fitted values \(\hat{x}_1, \dots, \hat{x}_K\) alongside the included controls \(Z_C\):

\[y = \beta_1 \hat{x}_1 + \cdots + \beta_K \hat{x}_K + \delta Z_C + \varepsilon\]

CRITICAL RULE: EXCLUDED INSTRUMENTS NEVER ENTER STAGE 2

Notice that \(Z_E\) does not appear directly in the second stage. By the exclusion restriction, \(Z_E\) affects \(y\) only through its influence on \(\hat{x}\). If \(Z_E\) were included in the second stage, it would eliminate identification because \(\hat{x}\) is a linear combination of \(Z_E\) and \(Z_C\), causing exact multicollinearity.

PROPER SOFTWARE ESTIMATION IS MANDATORY

Standard errors in the second stage must use proper IV/2SLS estimation routines (such as ivreg in Stata or IV2SLS in Python/R) — never ordinary OLS on \(\hat{X}\). Manual OLS fails to account for first-stage estimation uncertainty and computes residuals from \(\hat{X}\) rather than original \(X\).

💡

QUICK CHECK

If an econometric model contains 2 endogenous regressors but only 1 excluded instrument, how is the model classified, and can it be estimated via IV?

HINT: Compare the number of excluded instruments (\(L\)) to the number of endogenous variables (\(K\)) in the order condition.

ANSWER: The model is underidentified; IV estimation is not possible.

WHY? Identification requires at least as many excluded instruments as endogenous regressors (\(L \ge K\)). Here, \(L = 1\) while \(K = 2\), leaving fewer empirical moment conditions than structural parameters to estimate. The model is underidentified, and the causal parameters cannot be recovered.

📋

What You Should Now Understand

  • The general IV model partitions variables into endogenous regressors \(X\), included controls \(Z_C\), and excluded instruments \(Z_E\).
  • The order condition states that identification requires at least as many excluded instruments as endogenous variables (\(L \ge K\)).
  • Models are underidentified if \(L < K\), exactly identified if \(L = K\), and overidentified if \(L > K\).
  • In the first stage, each endogenous regressor is regressed on all included controls and excluded instruments to generate \(\hat{X}\).
  • In the second stage, outcome \(y\) is regressed on \(\hat{X}\) and \(Z_C\); excluded instruments \(Z_E\) are strictly omitted from the second stage.
