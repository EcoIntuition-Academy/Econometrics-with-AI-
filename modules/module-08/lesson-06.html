LESSON 8.6 Resampling & Review

Bootstrap Standard Errors & Module Review

When mathematical standard error formulas are intractable or rely on fragile distributional assumptions, the bootstrap approximates sampling variability by repeated empirical resampling. We examine the mechanics of bootstrapping, analyze its combinatorics, and synthesize Module 8 across 12 core knowledge cards.

LEARNING OBJECTIVES
  • Understand the motivation for bootstrap inference when analytical standard-error formulas are difficult or undesirable.
  • Master the bootstrap resampling algorithm: drawing with replacement to build an empirical sampling distribution.
  • Evaluate small-sample bootstrap combinatorics: \(n^n\) ordered samples vs \(\binom{n+r-1}{r}\) combinations with repetition.
  • Compute the empirical bootstrap estimator mean, variance, and standard error.
  • Synthesize all 12 core concepts of Module 8 and compare the five foundational econometric responses to non-spherical disturbances.

1. Bootstrap Resampling Mechanics

In complex econometric models, deriving an analytical standard-error formula (such as White's sandwich matrix) can be mathematically cumbersome or require large-sample asymptotic justifications that perform poorly in small samples. The bootstrap provides a computer-intensive alternative that approximates the sampling distribution directly through repeated resampling.

THE BOOTSTRAP RESAMPLING WORKFLOW
1. Observed Original Sample: \(\mathbf{x} = \{x_1, x_2, \dots, x_n\}\)
↓
2. Draw Sample of Size \(n\) WITH REPLACEMENT: \(\mathbf{x}^{*(b)}\)
↓
3. Recompute Estimator on Resample: \(\widehat{\theta}^{*(b)} = \widehat{\theta}(\mathbf{x}^{*(b)})\)
↓
4. Repeat for \(B\) Replications: \(\{\widehat{\theta}^{*(1)}, \dots, \widehat{\theta}^{*(B)}\}\)
↓
5. Compute Empirical Bootstrap Standard Error: \(\operatorname{SE}^*(\widehat{\theta})\)

Source Example: A 4-Observation Sample

Consider the exact numeric example from page 8 of the lecture notes:

SAMPLE OBSERVATIONS
$$\begin{aligned} \mathbf{x} &= \{2, 4, 9, 12\}, \quad n = 4 \\ \bar{x} &= \frac{2 + 4 + 9 + 12}{4} = 6.75 \end{aligned}$$

When drawing with replacement, any value can appear multiple times or not at all in a given resample:

  • Draw 1: \(\{2, 2, 9, 12\} \implies \bar{x}^{*(1)} = 6.25\)
  • Draw 2: \(\{4, 4, 4, 9\} \implies \bar{x}^{*(2)} = 5.25\)
  • Draw 3: \(\{12, 2, 12, 9\} \implies \bar{x}^{*(3)} = 8.75\)
COMBINATORICS · DISTINCT RESAMPLES OF SIZE 4

Ordered Possible Draws:

$$n^n = 4^4 = 256 \text{ sequences}$$

Each of the \(4\) slots in the bootstrap sample has \(4\) independent choices.

Distinct Combinations with Repetition:

$$\begin{aligned} \binom{n + r - 1}{r} &= \binom{4 + 4 - 1}{4} \\ &= \binom{7}{4} = \frac{7!}{4!3!} = 35 \end{aligned}$$

Accounting for unordered multisets, there are exactly \(35\) distinct empirical compositions.

Formal Bootstrap Estimator Formulas

Let \(\widehat{\theta}^{*(b)}\) be the statistic estimated from bootstrap replication \(b\) for \(b = 1, \dots, B\):

BOOTSTRAP MEAN OF ESTIMATES
$$\bar{\theta}^* = \frac{1}{B}\sum_{b=1}^B \widehat{\theta}^{*(b)}$$

Center of the empirical resampling distribution.

BOOTSTRAP VARIANCE
$$\operatorname{Var}^*(\widehat{\theta}) = \frac{1}{B - 1}\sum_{b=1}^B \big(\widehat{\theta}^{*(b)} - \bar{\theta}^*\big)^2$$

Empirical dispersion across the \(B\) resamples.

BOOTSTRAP STANDARD ERROR
$$\operatorname{SE}^*(\widehat{\theta}) = \sqrt{\operatorname{Var}^*(\widehat{\theta})}$$

Standard deviation of the bootstrap distribution.

4. Module 8 Core Knowledge Cards

Review the 12 foundational concepts established across all lessons of Module 8:

01 · SPHERICAL

Spherical Disturbances

Assumption that \(\mathbb{E}[\boldsymbol{\varepsilon}\boldsymbol{\varepsilon}' \mid \mathbf{X}] = \sigma^2 \mathbf{I}\), combining constant variance and zero error covariance.

02 · NON-SPHERICAL

Non-Spherical Errors

When \(\boldsymbol{\Omega} \neq \mathbf{I}\), causing conventional OLS standard errors and test statistics to be invalid.

03 · HETERO

Heteroskedasticity

Non-constant error variance (\(\sigma_i^2 \neq \sigma^2\)), common in cross-sectional samples where dispersion scales with unit size.

04 · AUTOCORR

Autocorrelation

Nonzero off-diagonal covariances (\(\operatorname{Cov}(\varepsilon_i, \varepsilon_j) \neq 0\)), commonly arising in time-series and panel data.

05 · OLS VARIANCE

True OLS Covariance

\(\operatorname{Var}(\widehat{\boldsymbol{\beta}}) = \sigma^2 (\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\boldsymbol{\Omega}\mathbf{X}(\mathbf{X}'\mathbf{X})^{-1}\); OLS remains unbiased but inefficient.

06 · GLS

Generalized Least Squares

Transforms variables by \(\boldsymbol{\Omega}^{-1/2}\) when \(\boldsymbol{\Omega}\) is known: \(\widehat{\boldsymbol{\beta}}_{\text{GLS}} = (\mathbf{X}'\boldsymbol{\Omega}^{-1}\mathbf{X})^{-1}\mathbf{X}'\boldsymbol{\Omega}^{-1}\mathbf{y}\).

07 · FGLS

Feasible GLS

Estimates \(\widehat{\boldsymbol{\Omega}}\) from preliminary OLS residuals, then applies the GLS formula to achieve asymptotic efficiency.

08 · WHITE HC0

White Robust Standard Errors

Sandwich estimator \((\mathbf{X}'\mathbf{X})^{-1}[\sum \widehat{\varepsilon}_i^2 \mathbf{x}_i \mathbf{x}_i'](\mathbf{X}'\mathbf{X})^{-1}\) preserving OLS point estimates.

09 · BREUSCH-PAGAN

Breusch–Pagan Test

Regresses squared residuals \(\widehat{\varepsilon}_i^2\) on explanatory variables; evaluates test statistic \(n R^2 \sim \chi^2_k\).

10 · WHITE TEST

White Test

Auxiliary regression including regressors, squares, and cross-products; evaluates \(n R^2 \sim \chi^2_q\) for general heteroskedasticity.

11 · WLS

Weighted Least Squares

Special diagonal case of GLS where observations are weighted by precision: \(\widehat{\boldsymbol{\beta}}_{\text{WLS}} = (\mathbf{X}'\mathbf{W}\mathbf{X})^{-1}\mathbf{X}'\mathbf{W}\mathbf{y}\).

12 · BOOTSTRAP

Bootstrap Standard Errors

Approximates sampling dispersion by drawing samples of size \(n\) with replacement and evaluating the standard deviation of estimates.

5. Methodological Comparison of Approaches

Summary of how the five foundational approaches address non-spherical disturbances:

Method Effect on Coefficients Information Required Primary Advantage
GLS Changes point estimates to \(\widehat{\boldsymbol{\beta}}_{\text{GLS}}\) Exact covariance matrix \(\boldsymbol{\Omega}\) known Attains BLUE minimum variance
FGLS Changes point estimates to \(\widehat{\boldsymbol{\beta}}_{\text{FGLS}}\) Model for \(\boldsymbol{\Omega}\) estimated from residuals Feasible in empirical practice; asymptotically efficient
White Robust SE Leaves OLS coefficients unchanged None (model-free; uses sample residuals) Asymptotically valid inference without modeling \(\sigma_i^2\)
WLS Changes point estimates to \(\widehat{\boldsymbol{\beta}}_{\text{WLS}}\) Observation weights \(w_i \propto 1/\sigma_i^2\) known BLUE efficiency for heteroskedasticity (e.g. group data)
Bootstrap SE Retains original estimator \(\widehat{\theta}\) Empirical sample data; repeated computing power Robust inference when standard error formulas are intractable

6. Quick Check & Understanding Test

CHECK 8.6 In the bootstrap procedure, what is the conceptual difference between the resample size and the number of replications? Click to Reveal Solution

Answer: Each individual bootstrap resample must contain exactly \(n\) observations (the original sample size) drawn with replacement, while the number of replications \(B\) is the number of times this entire resampling cycle is independently repeated on the computer.

Why? The resample size must match the actual sample size \(n\) so that the sampling variance of the bootstrap statistic mimics the true finite-sample sampling variability of the estimator on data of size \(n\).

In contrast, the replication count \(B\) (such as \(B = 50, 250, \dots, 1000\)) is a computational parameter. A larger \(B\) reduces Monte Carlo simulation error and maps out the empirical sampling distribution \(\{\widehat{\theta}^{*(1)}, \dots, \widehat{\theta}^{*(B)}\}\) with high fidelity.

TAKEAWAYS

What You Should Now Understand

  • Bootstrap standard errors estimate sampling variability by repeatedly resampling the observed sample with replacement.
  • For a sample of size \(n\), there are \(n^n\) possible ordered bootstrap draws and \(\binom{2n-1}{n}\) distinct combinations with repetition.
  • The standard deviation of estimates across \(B\) bootstrap replications yields a consistent estimator of the standard error.
  • Module 8 provides three practical avenues for non-spherical disturbances: re-weighting/transformation (GLS/WLS/FGLS), robust sandwich standard errors (White), or computational resampling (Bootstrap).
  • Diagnostic tests (Breusch–Pagan and White) allow researchers to statistically verify whether homoskedasticity holds before drawing inferential conclusions.
